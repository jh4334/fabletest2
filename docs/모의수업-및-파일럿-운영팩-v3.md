# 《마음의 문》 v3 모의수업·파일럿 운영팩

이 문서는 내부 모의수업과 3개 학교 파일럿을 같은 방식으로 기록하기 위한
실행 양식입니다. 실제 적용 전 값은 비워 두며, 관찰하지 않은 결과를 추정해
채우지 않습니다.

## 1. 적용 개요

| 항목 | 기록 |
| --- | --- |
| 학교·집단 코드 | `[예: S1-A / 실명 금지]` |
| 적용 일시 | `[YYYY-MM-DD, 교시]` |
| 적용 차시 | `[1~16차시]` |
| 참여 학생 수 | `[ ]명` |
| 교사·관찰자 수 | `[ ]명` |
| 기기 | `[Windows/Chromebook/iPad/Android/기타]` |
| 브라우저·버전 | `[ ]` |
| 실행 방식 | `[Pages/PWA/로컬 파일/교실 서버]` |
| 네트워크 | `[정상/불안정/차단]` |
| 접근성 설정 | `[큰 글씨/색약/읽어주기/효과 줄이기/저사양]` |

학생 이름, 학번, 연락처, 계정 ID는 적지 않습니다. 학생을 구분해야 하면
수업용 별명 또는 임시 번호를 사용합니다.

## 2. 수업 전 10분 점검

- [ ] 교사용 기기에서 링크 또는 PWA가 열린다.
- [ ] 새로고침 후 타이틀과 세 슬롯이 정상 표시된다.
- [ ] 사용할 슬롯을 백업했다.
- [ ] 선생님 방 → 수업 모드에서 오늘 구간과 연계 차시를 확인했다.
- [ ] 소리를 동시에 틀 기기 수를 정하고 음량을 낮췄다.
- [ ] 키보드 또는 터치 조작을 한 번 시험했다.
- [ ] 큰 글씨와 화면 효과 줄이기를 필요한 학생에게 미리 적용했다.
- [ ] 오프라인 적용이면 네트워크를 끈 뒤 재실행했다.
- [ ] 활동지와 종료 신호를 준비했다.
- [ ] 화면·기록에 실명이나 개인정보가 들어가지 않게 안내했다.

## 3. 40분 모의수업 시나리오

| 시간 | 교사 행동 | 학생 행동 | 관찰 포인트 |
| --- | --- | --- | --- |
| 0~5분 | 오늘 질문 1개와 개인정보 원칙 안내 | 별명 슬롯 선택, 조작 확인 | 첫 이동·결정 성공 |
| 5~25분 | 설명을 줄이고 막힌 학생만 3단계 힌트 안내 | 탐색·선택·대화 | 반복 막힘, 이탈, 협력 |
| 25~35분 | 선택 이유를 묻고 다른 해석 연결 | 활동지 작성·짝 대화 | 자기 말 설명, 관점 수정 |
| 35~40분 | 자동 저장 확인, 한 문장 정리 | 종료·소감 | 다음 행동으로 전이 |

교사 개입은 다음 순서로 제한합니다.

1. “화면 위 목표를 읽어 볼까?”
2. “조사하지 않은 반짝임이 있을까?”
3. “먼저 가만히 듣기를 골라 볼까?”
4. 마지막에만 구체적인 위치나 행동을 알려 줍니다.

## 4. 학생 행동 관찰지

학생별 또는 3~5명 표본을 골라 기록합니다.

| 학생 코드 | 첫 이동 무도움 | 첫 조사 무도움 | 힌트 단계 | 듣기 사용 | 선택 이유 설명 | 이탈·중단 | 메모 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `[ ]` | `[Y/N]` | `[Y/N]` | `[0~3]` | `[Y/N]` | `[0~2]` | `[분]` | `[ ]` |

선택 이유 설명은 `0=설명 못함`, `1=장면을 말함`, `2=장면과 생활 원칙을
연결함`으로 기록합니다.

## 5. 구간별 사건 기록

| 시각 | 구간·화면 | 관찰된 사실 | 영향 | 임시 대응 | 재현 여부 |
| --- | --- | --- | --- | --- | --- |
| `[ ]` | `[ ]` | `[해석 없이 본 것]` | `[개인/여럿/수업중단]` | `[ ]` | `[Y/N]` |

사실과 해석을 나눕니다. 예를 들어 “학생이 40초 동안 같은 벽에 세 번
부딪힘”은 사실이고, “맵이 재미없음”은 추가 질문이 필요한 해석입니다.

## 6. 학생 소감지

1. 오늘 가장 기억에 남은 장면은 무엇인가요? 왜 그랬나요?
2. 등장인물은 왜 그런 행동을 했다고 생각하나요?
3. 내가 고른 행동은 무엇이며, 다른 선택도 가능했나요?
4. 게임 밖에서 비슷한 상황을 만나면 무엇을 먼저 할 건가요?
5. 조작하거나 읽기 어려웠던 곳이 있었나요?
6. 재미 정도를 1~5로 표시하고 이유를 한 문장으로 적어 주세요.

## 8. 파일럿 지표 계산

| 지표 | 계산 | 실제 값 |
| --- | --- | --- |
| 첫 이동 성공률 | 무도움 첫 이동 학생 / 관찰 학생 × 100 | `[ ]% (n=[ ])` |
| 첫 조사 성공률 | 무도움 첫 조사 학생 / 관찰 학생 × 100 | `[ ]% (n=[ ])` |
| 수업 중단 오류 | 전체 수업을 멈춘 오류 건수 | `[ ]건` |
| 게임 이탈 비율 | 3분 이상 비과제 행동 학생 / 참여 학생 × 100 | `[ ]% (n=[ ])` |
| 행동 이유 설명률 | 설명 점수 1 이상 학생 / 응답 학생 × 100 | `[ ]% (n=[ ])` |
| 사전·사후 변화 | 같은 학생의 사후% - 사전% 평균 | `[ ]%p (n=[ ])` |
| 교사 준비 시간 | 링크 확인부터 수업 시작 준비 완료까지 | `[ ]분` |
| 교사 개입 | 수업당 직접 위치·정답 안내 횟수 | `[ ]회` |

모든 비율에는 분모 `n`과 적용 조건을 함께 씁니다. 사전과 사후를 모두 한
학생만 변화 계산에 포함합니다.

## 12. 공개 전 판단

- [ ] P0·P1 미해결 0건
- [ ] 16차시와 실제 시작 상태 불일치 0건
- [ ] 개인정보 포함 원자료가 저장소에 없음
- [ ] 자동 테스트와 브라우저 테스트 통과
- [ ] 최소 한 번의 오프라인 재실행 확인
- [ ] 파일럿의 한계와 응답 인원을 결과에 함께 표기

외부 학교 적용이 아직 이루어지지 않았다면 위 결과 칸을 빈 상태로 유지하고
“운영 도구 준비 완료, 현장 실측 대기”라고 보고합니다.
