# 스펙 — P1 수직 슬라이스: 1층 「개인정보 교실」

> 구현 대상. 기준서 v1의 헌법(§3)을 위반하는 구현은 반려된다.
> 목표: 타이틀 → 1층 클리어(계단 개방)까지 **완전히 동작하는 재미 검증판**.

## 1. 파일 구조 (신규 작성)

```
index.html        캔버스 720×528 + 로딩 + 터치 버튼(스틱·A) + sw 등록은 P3
src/art.js        assets/pack 로더: load(id,src)·ready(id)·drawTile()·drawChar()
src/data.js       맵·대사·퍼즐·배틀 데이터 (엔진과 분리, 한글 문자열은 여기만)
src/engine.js     루프·입력(키보드+터치 스틱)·충돌·상태머신·렌더·세이브
tools/validate.js 기존 파일 확장 (아래 §6)
tools/smoketest.js 스텁 교체 → 실검사 (아래 §6)
```

## 2. 에셋 계약 (검증 완료된 실측값)

- 타일 16px 원본 → 화면 3배(48px). 캔버스 720×528 = 15×11 타일.
- `assets/pack/char/student.png`(주인공)·`teacher_green.png`: **64×112 = 4열×7행 16px**.
  행 배치는 구현 시 실렌더로 확인해 `art.js`에 상수로 문서화할 것
  (걷기 4방향×4프레임이 상단 4행에 있음).
- `assets/pack/map/interior_floor.png`(352×272)·`wall_simple.png`(160×176):
  맵은 이 두 시트의 (col,row) 참조 그리드로 정의.
- **씌임 연출**: 캐릭터 위에 `rgba(40,20,60,0.65)` 보라-검정 오버레이 사각형/
  실루엣 + 눈만 보라 점 2개. 별도 에셋 금지.
- 발밑 그림자: `char/drop_shadow.png`(12×8).

## 3. 슬라이스 콘텐츠 (이것만, 더 만들지 말 것)

1. **타이틀**: 제목 + [시작] 하나. 슬롯 UI는 P3. (텍스트 2줄 이내)
2. **인트로**: 상자 3개 이내 — "방과 후 교실. 방송: 〈나비스 시스템 점검 중.
   전 출입구를 잠급니다〉. 복도로 나가 보자."
3. **1층 맵 2개**: 교실(15×11), 복도(20×11, 가로 스크롤 카메라).
4. **메커닉 — 노출도 게이지 (기준서 §2 1층)**:
   - 교실·복도에 **내 정보 카드 3장**(이름표·비밀번호 쪽지·사진)이 떨어져 있다.
   - 바닥의 **광고 단말**(crate.png 재활용)에 닿으면 카드를 1장 뺏기고 노출도 +1.
   - 노출도(0~5)가 오를수록 화면 가장자리에 광고 딱지가 늘어난다(사각형+文字).
   - 카드를 다시 주우면 노출도 -1. **HUD에 게이지 상시 표시 + 회복 방법 한 줄**.
5. **배틀 1회 — 짝꿍(그림자 씌임)**: 복도 끝에서 조우.
   - 턴: [말 걸기 / 보여주기 / 가만히 듣기] → 상대 턴은 **8초 탄막 회피**
     (하트 3, 0이 되면 "한 발 물러남" 후 재도전, 게임오버 없음).
   - 정답 루트: 듣기(속마음: "비밀번호 공유했더니 계정을 뺏겼어…") →
     보여주기[비밀번호 쪽지 카드] → 그림자 벗겨짐 → 손 내밀기.
   - 총 3~4턴. 대사는 전부 data.js, 상자당 2줄.
6. **클리어**: 짝꿍이 **약속 카드①「내 정보는 내가 지킨다」** 지급 →
   계단 문 열림 → "2층은 공사 중" 안내 = 슬라이스 끝.
7. **터치**: 좌측 가상 스틱 + 우측 A버튼 (index.html DOM, 이전 세대 방식 참고 가능).
8. **세이브**: localStorage 단일 슬롯 자동 저장(위치·노출도·카드·클리어 플래그).

## 4. 텍스트 예산 (슬라이스)

- **총 1,800자 이내.** 타이틀~첫 배틀 시작까지 상자 5개 이내(헌법).
- 대사 전량을 data.js에 두고 validate가 자동 집계한다.

## 5. 조작

키보드: 화살표/WASD 이동, Z/Space 결정·조사, X/Esc 취소. 터치: 스틱+A.

## 6. 테스트 (반드시 게이트 그린으로 마감)

- `tools/validate.js` 확장: 맵 그리드 정합(크기·워프 좌표·시트 범위),
  카드 3장 존재, 어휘 린트·텍스트 예산(기존 로직 재사용).
- `tools/smoketest.js` 교체: node vm 샌드박스로 engine+data 로드 →
  ①이동·충돌 ②카드 줍기→노출도 감소 ③광고 단말 접촉→노출도 증가
  ④배틀 진입→정답 루트 완주→클리어 플래그 ⑤세이브/로드 왕복. 20검사 이상.
- 완료 기준: `npm run validate && npm test` 그린 + file:// 로드 시 콘솔 에러 0.

## 7. 금지

- 2층 이상·교사도구·PWA·BGM 구현 금지(스코프 아웃).
- 한글 문자열을 engine.js에 하드코딩 금지(어휘 린트가 data.js·index.html만 봄).
- 이전 게임 코드 복사-붙여넣기 금지(참고는 가능, git show로).
