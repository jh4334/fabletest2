# 스펙 — P7: 교사 도구 (대시보드 · 차시 모드 · 진단 리포트)

> 본편 완결(v0.7.0) 위에 얹는 교실 운영 계층. 헌법(§3) 위반 반려.
> **학생 화면은 건드리지 않는다** — 아이는 게임만 본다(스텔스 교육 원칙).
> 버전 0.8.0.

## 0. 목표

교사가 ①수업 중 원하는 층부터 바로 시작 ②우리 반 아이가 어디서 막혔는지 확인
③차시 계획과 대응 확인 을 게임 안에서 할 수 있게 한다.

## 1. 진입 (학생 눈에 띄지 않게)

- **타이틀에서만** 진입. 키보드 `T`, 터치는 타이틀 우하단 작은 [선생님] 버튼
  (본편 플레이 중에는 어떤 키로도 열리지 않는다 — 수업 중 오조작 방지).
- 진입 시 화면 전체가 교사 화면(mode `teacher`). `X`/취소로 타이틀 복귀.
- 저장이 없어도 안전하게 열려야 한다(빈 리포트 표시).

## 2. 화면 3탭 (좌우로 전환, 탭 이름 상단 표시)

### 탭1 「수업 시작」 — 차시 모드
- 6개 버튼: 1층~5층·옥상. 고르면 **그 층 시작 상태로 즉시 진입**
  (필요한 이전 층 clearedOf·stairsOpen을 자동 채움, 게이지는 0, 카드는 초기 배치).
- 아래 한 줄: 해당 층의 주제·소요 안내(예: `1층 · 개인정보 · 퍼즐2+배틀1 · 약 12분`).
- **주의**: 진입 시 기존 저장을 덮어쓰므로 확인 1회(기존 확인창 문법 재사용).

### 탭2 「우리 반 기록」 — 진단 리포트
- 현재 기기의 저장 1건을 읽어 표로:
  진행(최고 도달 층·되돌린 사람 수), 시간, 뺏긴 카드, 물러난 횟수,
  스티커 오답, 약속 오답, 고른 엔딩.
- **해석 한 줄**을 규칙 기반으로 붙인다(수치가 아니라 지도 힌트):
  - 뺏김 ≥3 → `개인정보를 자주 흘렸어요. 1층 광고 단말 이야기를 함께.`
  - 물러남 ≥3 → `배틀이 어려웠어요. 듣기 먼저를 다시 안내.`
  - 약속 오답 ≥3 → `층별 약속 연결이 헷갈려요. 다섯 약속을 함께 정리.`
  - 해당 없음 → `고르게 잘 해냈어요.`
- [기록 지우기] 버튼(확인 1회) — 다음 학생을 위해.

### 탭3 「차시 안내」 — 수업 대응표
- 6줄: 층 ↔ 주제 ↔ 핵심 메커닉 ↔ 발문 1개.
- 문서(docs/차시-대응표)와 **같은 내용**을 게임 안에서도 보게 한다.

## 3. 제약

- 학생 진행에 영향을 주는 상태 변경은 탭1(차시 시작)·기록 지우기 뿐.
- 새 UI 컴포넌트 발명 금지 — 기존 panel/txt/커서 문법 재사용.
- 한글 문자열은 data.js(D.TEACHER)에만. 새 바이너리 에셋 금지.
- 개인정보 수집 없음 — 이름·학번 입력란을 만들지 않는다(기기 로컬 1건만).

## 4. 게이트

  실제 맵의 걸을 수 있는 칸), 해석 규칙 임계값 존재, 텍스트 예산.
- 스모크 +25건: T키 진입·X 복귀, 본편 중에는 T가 무시됨, 탭 전환,
  차시 시작(확인→상태 세팅→해당 맵 진입), 저장 없을 때 빈 리포트,
  해석 규칙 4종 분기, 기록 지우기(확인 포함), **기존 482건 전수 존속**.
- browsertest: 교사 화면 3탭 스크린샷 + T키 진입/복귀 검사.
