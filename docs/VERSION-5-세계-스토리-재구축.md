# VERSION 5.0 · 세계와 이야기 재구축

## 화면에서 확인되는 변화

- 매 페이지 로드마다 게임보다 먼저 `VERSION 5.0` 확인 게이트가 열린다.
- 첫 맵 `introlab`과 귀환 허브 `village`는 구 마을 타일 장식을 그리지 않는다.
- 두 맵 모두 방사형 프로젝트 0호 보관소 원화를 월드 좌표에 고정해 사용한다.
- 기존 집, 연못, 폐허 바위, 가로등 오버레이는 이 두 맵에서 숨긴다.
- 첫 목표는 단서 수집/실험실 탈출이 아니라 `경계·의심·거절` 봉인 복구와
  `게이트 01` 개방이다.

## 이야기의 새 출발점

플레이어는 화면 속에 우연히 떨어진 아이가 아니다. 영이가 삭제 직전에 남긴
마지막 질문, “AI를 안전하게 만든다는 결정은 누가 내려야 하지?”의 백업이다.
반디는 삭제 명령을 피한 안내 조각이며, 여섯 보스는 제거해야 할 괴물이 아니라
영이에게서 분리된 안전 약속이다.

따라서 여정의 목적도 “영이를 고친다”에서 다음으로 바뀐다.

1. 여섯 삭제 구역에서 경계·의심·불확실성·멈춤·거리·거절을 복구한다.
2. 박사의 일방적인 안전 결정을 추적하고 책임을 묻는다.
3. 마지막에는 정답을 대신 선택하지 않고, 영이에게 권리와 선택권을 돌려준다.
4. 플레이어는 영이의 대답을 기다리는 증인이 된다.

## 세이브와 배포

기존 세이브 진행도는 유지한다. 다만 v5에서 처음 이어하기 할 때 새 세계관과
주인공 정체를 전체 대화 장면으로 한 번 안내한다. 정적 자원 캐시는 v5 자산
해시로 교체하며, HTML과 게임 코드는 네트워크 우선으로 갱신한다.
