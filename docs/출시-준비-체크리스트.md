## 1. 검증 상태 (자동)

| 검사 | 명령 | 상태 |
|---|---|---|
| 데이터·어휘·좌표·개인정보 린트 | `npm run validate` | CI 게이트 |
| 로직 스모크(1009) + 슬롯(24) | `npm test` | CI 게이트 |

  안 하면 validate 실패. 서비스워커 캐시 버전이 자산 해시와 묶여 있음.

## 2. 기능 체크리스트

### 핵심 플로우
- [ ] 새 슬롯 → 이름 입력 → 프롤로그 진입
- [ ] 방탈출 퍼즐 클리어 → 증거 카드 획득
- [ ] 마음 조각 배틀(듣기→말 걸기→안아 주기) → 자비 선택

- [ ] 엔딩 후 마을 복귀 → 후일담 대사

### 실패·경계 상태
- [ ] 배틀 탈진 → "잠시 물러났다" 재도전(기억 유지)

- [ ] 크래시(프레임/전역 예외) → 복구 화면(Z 마을 / X 타이틀)
- [ ] 잘못된 백업 파일 → "불러올 기록이 없어요" 안내
- [ ] JS 꺼짐 → `<noscript>` 안내

### 데이터 안전
- [ ] 백업 복원 후 "↩ 되돌리기"로 취소 가능
- [ ] 슬롯 삭제 후 R키로 되살리기 가능
- [ ] 슬롯 3개 데이터 분리 저장

## 7. 롤백 계획

- **대상**: GitHub Pages 배포(정적 파일).
- **롤백 조건**: 배포 후 게임이 시작되지 않음 / 크래시 급증 / 진행
  저장 실패 보고.
- **방법**: `git revert <문제 커밋> && git push` → pages.yml이 검증
  통과 후 이전 상태로 재배포. 또는 Actions에서 직전 성공 배포 워크플로를
  `Re-run`.
- **데이터 영향**: 사용자 데이터는 각 기기 localStorage에만 있어 배포
  롤백과 무관(유실 없음). 단, 세이브 스키마를 올리는 변경을 롤백할 땐
  구 코드가 신 세이브를 읽어야 하므로, **스키마 변경 전후 migrateSlotVN
  하위호환**을 유지할 것(현재 v8, migrateSlotV6~V8 존재).
- **롤백 후 검증**: 새 창(시크릿)으로 접속 → 두 번 새로고침(서비스워커
  갱신) → 타이틀·새 게임·배틀 1회 확인.

## 9. 버전 고정 정책 (학기 중 stable 태그)

학기 중에는 수업이 예고 없이 바뀌지 않도록 **한 학기 = 한 stable 버전**을
기본으로 한다. main은 계속 발전하되, 교실에는 고정된 태그를 안내한다.

- **stable 태그 고정**: 학기 시작 전, 검증을 통과한 커밋에 `git tag stable-YYYY-학기`
  (예: `stable-2026-2학기`)를 달고 push한다. 교사 안내 문서에는 이 태그를 배포한
  URL(또는 태그 릴리스)을 링크한다. 학기 중 급한 버그 수정만 이 태그에
  cherry-pick하고, 기능·대사 변경은 다음 학기 태그로 미룬다.
- **왜**: 서비스워커가 cache-first라, 학기 중 자산이 바뀌면 학생마다 갱신
  시점이 어긋나(§7 참고) 같은 교실에서 화면이 달라질 수 있다. 태그 고정은
  이 편차와 "어제와 오늘 문답이 다르다"는 혼란을 막는다.
- **세이브 호환 불변식**: 학기 중 어떤 반영이든 세이브 스키마(`SAVE_VERSION`)를
  낮추지 않는다. 올릴 때는 `migrateSlotVN` 하위호환을 반드시 붙여, 태그를
  롤백해도 구 코드가 신 세이브를 읽게 한다(§7). NG+ 같은 대사 스왑은 `flags`에만
  얹어 스키마에 영향이 없도록 한다.
- **변경 기록**: 학기별·라운드별 변경은 `CHANGELOG.md`에 요약한다. 교사에게는
  "이번 학기 무엇이 바뀌었나"를 CHANGELOG 링크로 한눈에 보여 준다.

## 10. 수동 QA 시나리오 (요약)

`docs/체크리스트-모바일-실기기.md`의 실기기 항목과 함께 수행.

1. 신규 사용자: 첫 로딩 → 이름 입력 → 프롤로그 배틀까지 막힘 없이.
2. 핵심 성공: 1장 방탈출 3구역 → 담아 배틀 → 자비 선택 → 클리어.
3. 실패 처리: 배틀 탈진 → 재도전. 잘못된 백업 파일 → 안내.
4. 데이터 안전: 슬롯 삭제 → R 되살리기. 백업 복원 → 되돌리기.
5. 새로고침/뒤로가기: 진행 중 새로고침 → 이어하기로 복원.
6. 중복 입력: 대화 중 Z 연타 → 건너뛰기만, 상태 깨짐 없음.
7. 모바일: 390px 세로 → 회전 안내, 가로 → 스틱·버튼 조작.
8. 접근성: TTS·큰 글씨·색약·효과 줄이기 각각 켜고 1장 진행.
