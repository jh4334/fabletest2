# R라운드 — 행동 배틀: 윤리는 어렵지만, 행동할 때 의미가 있다

2026-07-17. 참고: `jh4334/ethicslovable`(16차시 미디어·AI 리터러시 퀘스트)의
게임 문법과 「충북형 AI 윤리 가이드라인」 4대 가치. 기준서 v4를 보완한다.

## 원칙

1. **패턴 = 보스의 이름.** 상대 턴의 본체는 탄막이 아니라 보스의 행동이다.
   보스는 자기 행동을 상자 안에 투사하고, 아이는 그 행동의 *반대(윤리적
   행동)*를 몸으로 해야 마음이 열린다. 탄막은 가벼운 배경 리듬으로 강등.
2. **쉬운 길은 아프다.** 편한 행동(따라가기·받기·쏠리기·누르기·안주하기)이
   불이익, 어려운 행동(내 길·돌려주기·반례·확인·결단)이 보상 — "윤리는
   어렵지만 지킬 때 의미가 있다"를 조작감으로 체험.
3. **방탈출 = 리허설, 보스 = 실전.** 구역 방탈출이 같은 동사를 연습시키고
   (접수처=안 주기, 편집실=원본 대조…), 보스 첫 파도는 **연습 파도**(피해
   없음·안내 표시), 이후 파도부터 실전 강도.
4. 읽기 게이트(Q라운드)는 그대로 — 듣기·대답이 마음을 열고, 패턴 카운터가
   행동을 검증한다. 두 축이 함께 spareReady를 만든다.

## 수치 (기본)

- 연습 파도: turnCount 0의 wave — 피해 무효, 패턴 절반 강도, 상단 안내
  「연습 — ○○을 해 보자」. 리듬 유지를 위해 시간은 그대로.
- 패턴 가동: shaken·open (closed는 듣기 유도 단계라 탄막만 약하게).
- 탄막 간격: 패턴 보스 전원 rateMul ×1.4 (밀도 약 30% 하향).
- 카운터 보상: 운반·판정류 +8~10, 응시·회피류 +6~8, 3회 누적 시 만충 직전
  (기존 규칙 유지). 불이익: 게이지 -4 또는 피해 1 (보스별 표 참고).

## 리허설 다리

- 구역 클리어 대사 끝에 반디 브리지 1줄: "방금 한 거, ○○ 앞에서 그대로
  쓸 거야." (7곳)
- 교사용 안내서에 패턴↔윤리↔차시 매핑표 수록.
