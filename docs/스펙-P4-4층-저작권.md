# 스펙 — P4: 4층 「미술실 · 생성AI와 저작권」

> 기준서 §2의 4층. v0.4.0(1~3층) 위에 증축. 헌법(§3) 위반 반려.
> 이 스펙 밖의 것을 만들지 말 것 (5층·옥상·교사 도구·BGM 금지).

## 0. 목표

3층 클리어 → 계단이 4층으로 → 4층(출처 스티커 퍼즐 + 배틀 1) 클리어 →
"5층은 공사 중" → 클리어 화면. 40분 1차시. 버전 0.5.0.

## 1. 층 구조

- 맵 3개: `hall4`(4층 복도, 20×11, fl:4) + `artroom`(미술실 허브, 15×11) +
  `gallery`(전시 복도, 20×11 — 그림이 걸린 벽, 배틀 무대).
- hall3 계단 → hall4. gallery 끝 계단 → 클리어("5층은 공사 중").
  계단은 배틀 지점 인접(3층 교훈 유지).
- 4층 무드 컬러: 물감보라 `rgba(168,106,216,0.10~0.14)`.

## 2. 4층 메커닉 — 「출처 스티커」 (개념=메커닉)

**개념**: 남의 것을 내 것처럼 걸면 문이 닫힌다. 출처를 밝혀야 세계가 열린다.

- 전시 복도(gallery)에 **그림 액자 3점**이 걸려 있고, 각 액자 앞 통로에
  **잠긴 유리문**이 하나씩 있다(진행을 막음).
- 각 그림은 "미술 선생님이 AI로 만들어 자기 작품처럼 전시한 것".
  액자를 조사하면 **어딘가 이상한 점**이 보인다(손가락 6개, 서명이 뭉개짐,
  똑같은 구도 반복 — 생성AI 산출물 특징을 관찰 학습).
- 미술실(artroom)에서 **출처 스티커 3장**을 만든다: 스티커 제작대(콘솔 문법
  재사용)에서 그림마다 [AI로 만들었어요 + 원본 스타일 작가 표기] 스티커 선택.
  **어느 그림에 어느 스티커인지**는 액자의 '이상한 점'과 미술실의 자료
  (스타일 견본 카드)를 대조해야 안다 — 이게 퍼즐.
- 올바른 스티커를 액자에 붙이면 그 유리문이 열림 + 정직 게이지 +1(0~3,
  숫자 병기). **틀린 스티커는 벌 없이** "…뭔가 안 맞는 것 같다"로 되돌림
  (низ학년 배려, 오답 기록만 stats).
- 3점 모두 표기 → 미술 선생님(그림자)이 전시 복도 끝에 나타남.

## 3. 증거 카드 (4층 3장, floor:4)

| id | label | 위치 | 의미 |
|---|---|---|---|
| styleCard | 스타일 견본 | artroom | 원작자 화풍 견본(대조용) |
| aiReceipt | 생성 기록 | artroom(잠긴 서랍 — 스티커 1장 붙이면 개방) | AI 생성 로그 |
| firstSketch | 첫 스케치 | gallery | 선생님이 직접 그리던 옛 스케치 |

- 배틀 정답 증거 = `firstSketch` — "직접 그리던 시절의 손" (속마음과 맞물림).

## 4. 배틀 — 미술 선생님(그림자)

- `D.BATTLES.artTeacher`: name `미술 선생님`, shadow 3, hearts 3,
  evidence `firstSketch`, sheet `teacher`(green — bro와 다른 맵이라 무충돌).
- 속마음(listen): `「AI 그림이 내 스케치보다 예뻤어.」`
  `「…내 손이 부끄러워졌어.」`
- 정답 제시: `「이 서툰 선… 내 거였지.」` — 도구가 아니라 감추는 게 문제였음을
  깨닫는 결. 약속 카드④ 「만든 도구와 출처를 밝힌다」.
- 탄막: 기존 3종 + 신규 `paint`(위에서 느리게 떨어지다 바닥에 잠깐 남는
  물감 방울 — 남은 자국 위 지나면 피격. 동시 자국 3개 이하, 저학년 속도).
- 말걸기 3단·절반 기억 공통 문법 유지(artTeacher용 대사 세트).

## 5. 예산·게이트

- 4층 신규 텍스트 **1,700자 이내**(SLICE_BUDGET 5400→7200). 4층 진입~배틀
  상자 5개 이내 검사 추가.
- validate: fl:4, 4층 카드 3장, artTeacher 프로필, **그림↔스티커↔이상한 점
  매핑 정합**, 유리문 전부 잠김 상태 BFS 도달성(카드·제작대·액자 모두 접근
  가능해야 함 — 소프트락 차단), paint 탄막 수치 상한.
- 스모크 +30건 이상: 계단 연결, 액자 조사→이상한 점, 틀린 스티커 무벌 반려,
  올바른 스티커→문 개방+게이지, 서랍 개방, 3점 완료→선생님 등장, 배틀
  정답/오답/절반 기억, paint 자국 피격·소멸, 클리어 층 표기,
  **1~3층 회귀 262건 전수 존속**.
- browsertest: 스티커 부착 전/후 액자 픽셀 비교 + 배틀 스크린샷.
- `npm run bump`. 버전 0.5.0(engine·package 동기).

## 6. 구현 힌트

- 유리문: LEGEND 신규 문자(잠김=솔리드, 개방 시 S.opened[mapName] 오버레이로
  통행화 — 3층 안개의 역방향, 같은 합성 지점 재사용).
- 스티커 제작대·액자 상호작용: 3층 콘솔 문법 재사용. 새 UI 발명 금지.
- 액자·스티커·유리문·물감: 팩 팔레트 절차 도트. 새 바이너리 금지.
- 주의: 대회 심사 관점상 "AI 그림 = 나쁨"이 아니라 **"감추는 것"이 문제**로
  일관되게(기준서 §1 책임 프레임). 스티커 문구도 도구 명시+출처 표기 톤.
