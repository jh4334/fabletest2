# 기획서 v2 — 「AI 윤리 어드벤처: 마음의 문」 (리부트)

> 상태: 기획 확정안 (구현 전) · 대상: 초등 고학년(5~6학년) 기준
> 이 문서는 기존 빌드(v1)의 설계 진단을 바탕으로 게임 코어를 재설계한 기획서입니다.
> v1의 교사 도구·접근성·데이터 자산은 유지하고, 게임플레이 코어를 교체합니다.

---

## 0. 한 줄 정의

**정답을 고르는 게임이 아니라, 오개념을 가진 상대를 설득하는 게임.**
플레이어는 챕터마다 ① 개념을 몸으로 겪는 **방탈출 퍼즐**을 풀고,
② 거기서 얻은 **증거 카드**로 몬스터와 **설득 배틀**을 벌인다.

## 1. 왜 리부트인가 (v1 진단 요약)

v1은 포켓몬(탐험·수집·뱃지) + 언더테일(자비·탄막) + 퀴즈가 결합된 구조였으나,
코드 수준 분석 결과 다음이 확인됨:

| 문제 | 근거 (v1 코드) |
|---|---|
| 성장 축 부재 — 레벨·파티·능력치 없음, HP 매 배틀 고정 | game.js `startBattle` (maxHearts 고정) |
| 탄막 회피가 결과에 영향 0인 연출 — 하트가 1 밑으로 안 내려가고 무조건 복귀 | game.js `updateDodge` |
| 배틀의 실체가 3지선다 통행료 — 오답 선택지가 노골적이라 사고 부하 낮음 | data.js `QUIZZES` |
| 21개 맵이 상호작용 4~6개짜리 복도 — 탐험의 발견감 없음 | data.js `MAPS`, `MAP_PROPS` |
| 실패의 의미 없음 — 패배 페널티 0, 긴장 0 | game.js `loseBattle` |
| 텍스트 약 7.8만 자 대 인터랙션 소수 — 읽기 중심 | data.js 전반 |

**결론**: 좋았던 것(자비 시스템, 몬스터 서사, 탄막 엔진, 교사 도구)은 전부
언더테일 계열이고, 약했던 것은 전부 포켓몬 껍데기였다.
→ **포켓몬 구조 폐기, 언더테일 단일 노선으로 재설계.**

## 2. 디자인 필러 (모든 결정의 기준)

1. **개념이 곧 메커니즘** — 윤리 개념을 대사로 설명하지 않고, 퍼즐의 규칙으로
   겪게 한다. (필터버블 방은 추천만 따라가면 *실제로* 방이 좁아진다.)
2. **지식은 무기다** — 퍼즐·탐험에서 얻은 배움(증거 카드)이 배틀에서 실제로
   쓰인다. 배운 것이 게임 안에서 힘이 된다.
3. **실패는 배틀 안에, 안전망은 배틀 밖에** — 조우 안에서는 잃을 것이 있어
   긴장이 생기고, 조우 밖에서는 벌칙 없이 재도전한다. 게임오버 화면은 없다.
4. **이기는 게 아니라 이해시키는 것** — 몬스터는 적이 아니라 오개념을 가진
   아이. 전투의 목표는 HP 0이 아니라 마음 열기다. (v1의 정체성 계승)

## 3. 대상과 난이도 정책

- **기본 밸런스 = 고학년(5~6학년).** 퍼즐은 2~3겹, 정답 스포일 금지,
  오답 선택지는 "그럴듯한 오개념"으로 작성. 탄막은 실제로 맞는 난이도.
- 기존 난이도 옵션(저학년/기본/고학년)은 유지하되 의미를 재정의:
  - 저학년: 탄막 속도 −40%, 퍼즐 힌트 자동 1단계 공개, 하트 +1
  - 기본: 탄막 속도 −20%
  - 고학년(기본값): 본 기획서 수치 그대로
- 접근성(TTS·큰 글씨·색약 모드)은 전부 유지.

## 4. 전체 구조

```
프롤로그(튜토리얼) ─ 1장 ─ 2장 ─ 3장 ─ 4장 ─ 5장 ─ 파이널(코어)
                    │      │      │      │      │
                 방탈출  방탈출  방탈출  방탈출  방탈출
                 +배틀   +배틀   +배틀   +배틀   +배틀
```

- **선형 진행.** 오픈 맵·뱃지 게이트 폐기. 각 챕터는 압축된 한 구간.
- **챕터 공통 리듬**: `도입(1~2분) → 방탈출 퍼즐(6~8분) → 보스 설득
  배틀(5~6분) → 마무리·배움 카드 정리(1분)` — 합계 15~18분.
- **배틀은 챕터당 보스 1회뿐.** 설득 배틀은 한 판이 5~6라운드짜리
  세트피스(약 5분)라 잡몹 개념이 성립하지 않는다. 배틀하는 몬스터는
  전체 8종: 프롤로그 베껴몬 + 챕터 보스 5 + 파이널 2(어둠대왕몬·???).
- **일반 조우 몬스터는 폐기가 아니라 역할 전환** — 방탈출 안의 등장
  캐릭터가 된다. 방에서 쌓인 그 캐릭터와의 관계가 보스전 서사로 이어진다.
- **1챕터 = 1차시.** 40분 수업 기준 게임 15~18분 + 활동지.
  프롤로그는 1차시 도입에 포함, 파이널은 5차시 마무리(또는 자율 과제).
  → 기존 「차시별 활동지 5차시」와 처음으로 1:1 대응.
- 수업 모드(챕터 바로 시작)·퀴즈 챌린지·복습 노트는 유지. 설득 연습이
  더 필요한 학생은 퀴즈 챌린지의 「설득 연습 모드」(보스 재대결)로 보충.

### 챕터 라인업 (주제 재배치)

| 챕터 | 주제 | 방탈출 | 보스 (설득 배틀) | 방의 등장 캐릭터 (v1 몬스터 역할 전환) |
|---|---|---|---|---|
| 프롤로그 | AI 사용의 정직·저작권 | (미니) | 베껴몬 (튜토리얼) | — |
| 1장 | 개인정보·디지털 발자국 | 흔적의 방 | 수집몬 (카페 주인) | 몰래몬(정보 요구 단말기), 기록몬(지워지지 않는 게시판) |
| 2장 | 필터버블·알고리즘 편향 | 거울 복도 | 편향몬 (=문지기 로봇) | 갇힘몬(추천 문 안내인), 무시몬(같은 말만 하는 주민) |
| 3장 | 가짜뉴스·딥페이크·AI 환각 | 진실의 편집실 | 환각몬 (편집장) | 거짓몬(가짜 기사 납품), 합성몬(합성 사진 담당) |
| 4장 | 계정 보안·피싱·다크패턴 | 미끼의 미로 | 유혹몬 (미로의 설계자) | 뚫림몬(계정 털린 피해자), 멋대로몬(폭주 광고 기계) |
| 5장 | AI와 감정·의존·관계 | 속삭임의 방 | 홀림몬 (=안내 음성 「루미」의 정체) | 속삭임몬(문 너머 속삭임), 중독몬(소파 코너) |
| 파이널 | 만든 것에 대한 책임 | 코어(증거 봉헌) | 어둠대왕몬 → ??? | 조각몬(제단 안내) |

> 2장 문지기 로봇이 곧 보스(편향몬)이고, 5장 안내 음성 루미의 정체가
> 보스(홀림몬)다 — 방탈출에서 겪은 상대와 보스전에서 마주 앉는 구조.
> v1에서 보너스 맵에 격리돼 있던 생성형 AI 주제(환각몬·합성몬)는 3장
> 본편으로 승격. 표에 없는 v1 몬스터(악플몬·소문몬·펑펑몬 등)는 마을
> NPC 또는 퀴즈 챌린지로 이동 — 폐기하지 않고 밀도만 조절.

## 5. 방탈출 퍼즐 상세 설계

### 공통 규칙

- **정답 표지판 금지.** 힌트는 3단계 점진 공개(H키/힌트 버튼):
  1단계 "무엇을 봐야 하는지" → 2단계 "왜 그런지" → 3단계 "무엇을 하면 되는지".
  힌트 사용은 슬롯별로 기록되어 교사 리포트에 반영.
- **실패가 가르친다.** 잘못된 시도는 막다른 벽이 아니라 개념의 결과를
  보여주는 피드백이어야 한다. (아래 각 방의 "실패 피드백" 참조)
- **클리어 보상 = 증거 카드 2장.** 그 챕터 배틀에서 결정적 카운터로 쓰인다.
- 목표 소요 6~8분, 힌트 풀사용 시 4분.

### 1장 — 흔적의 방 (개인정보·디지털 발자국)

**무대**: 수집몬이 운영하는 "무료 게임 카페". 입구에서 경품을 미끼로
개인정보를 요구한다.

**메커니즘**:
- 플레이어는 정보 토큰 5개(닉네임·학교·집주소·전화번호·얼굴사진)를 소지.
- 방 곳곳의 단말기가 편의(지름길 개방, 지도 표시, 경품)를 대가로 토큰을 요구.
- 벽면 「프로필 보드」에 제공한 정보가 실시간 조합됨. **3개 이상 모이면
  보드가 완전한 프로필을 완성하고, 그림자 스토커가 생성되어 따라다닌다**
  (추적 압박 — 개인정보 조합의 위험을 체감).
- 「지우개 단말」에서 제공 정보를 삭제할 수 있으나, **"친구 게시판"에 공유된
  정보는 스크린샷 조각이 남아 완전 삭제 불가** (잊힐 권리의 한계).
- 출구는 두 개: 화려한 「VIP 출구」(정보 전부 요구 — 함정) vs 수수한 일반
  출구(**닉네임 하나만 요구** — 데이터 최소화 원칙).

**클리어 조건**: 프로필 보드 게이지를 임계 이하로 유지한 채 일반 출구 통과.
**실패 피드백**: 정보를 다 주고 VIP 출구로 가면 문이 열리긴 하지만 스토커
3마리가 함께 나오며 "이미 알려진 정보는 문을 닫아도 따라온단다" 연출 후
지우개 퀘스트로 유도 — 막히는 게 아니라 결과를 보여줌.
**증거 카드**: 「최소한의 정보」 「지워지지 않는 발자국」

### 2장 — 거울 복도 (필터버블·알고리즘 편향)

**무대**: 문마다 "당신이 좋아할" 미리보기가 뜨는 복도.

**메커니즘**:
- **추천 문(반짝임)에 들어갈 때마다 거의 같은 방이 나오되, 방이 한 뼘씩
  좁아지고 포스터가 같은 그림으로 통일되며 BGM에서 악기가 하나씩 빠진다.**
  화면 구석 「만족도」 게이지는 올라가는데 미니맵은 줄어든다 — 편안함과
  좁아지는 세계의 긴장을 말이 아니라 화면으로 보여줌.
- 탈출에는 「다른 목소리」 조각 3개가 필요. 조각은 **비추천 문**(칙칙하고
  "관심 없음" 딱지가 붙은 문) 뒤의 세 방에만 있다. 각 방의 NPC는 서로
  다른 의견을 말하고, 대화해야 조각을 얻는다.
- 2겹 퍼즐(편향): 마지막 문의 문지기 로봇이 "모자 쓴 사람은 위험하다"며
  통과를 거부한다(학습 데이터가 치우친 탓). 방 안의 **반례 사진 카드**를
  찾아 로봇에게 3장 학습시키면 판단이 교정되어 문이 열린다.

**클리어 조건**: 다른 목소리 3개 수집 + 문지기 로봇 재학습.
**실패 피드백**: 추천 문만 5회 연속 → 방이 1인 폭까지 좁아지고 모든 문이
같은 문이 되는 순간 "…여기, 처음이랑 같은 방이야?" 독백 → 처음 방으로
리셋되며 비추천 문에만 희미한 빛이 남는다.
**증거 카드**: 「추천의 정체」 「고장 난 저울」

### 3장 — 진실의 편집실 (가짜뉴스·딥페이크·AI 환각)

**무대**: 송출 마감 전의 뉴스 편집실. 책상 위에 뉴스 카드 6장.

**메커니즘**:
- 진짜 3장만 골라 송출기에 넣어야 한다. 각 가짜 카드에는 **검증 도구로
  발견 가능한 명확한 단서가 정확히 하나씩** 있다:
  - 원본 대조기: 사진이 좌우 반전·잘림, AI 생성 티(손가락 6개, 그림자 모순, 뭉개진 글자)
  - 출처 단말기: 인용된 신문사·논문이 존재하지 않음(AI 환각 체험)
  - 달력: 사건 날짜가 기사 날짜보다 미래
- **가짜를 송출하면 벽면 스크린 전체로 순식간에 퍼지고**, 소문 유령들이
  생겨나 이동을 방해한다. 이를 지우려면 「정정 보도」를 만들어 송출해야
  하는데 **거짓 1장 퍼뜨리는 데 클릭 1번, 정정에는 3단계 작업**이 든다 —
  거짓은 빠르고 정정은 느리다는 비대칭을 몸으로 겪게 함.
- 검증 없이 감으로 넣는 것을 막기 위해, 송출기는 "검증 도장"이 찍힌
  카드만 받는다(각 카드를 최소 1개 도구에 통과시켜야 함) — 횡적 읽기
  (lateral reading) 습관의 게임화.

**클리어 조건**: 진짜 3장 검증·송출 (가짜 송출 시에도 정정으로 복구 가능).
**증거 카드**: 「출처 확인」 「거짓의 속도」

### 4장 — 미끼의 미로 (계정 보안·피싱·다크패턴)

**무대**: "무료!" "당첨!" 간판이 번쩍이는 미로.

**메커니즘**:
- **반짝이는 지름길 문 = 전부 미끼.** 들어가면 입구로 되돌아오며 화면
  가장자리에 광고 딱지가 하나 붙는다(시야 방해 누적). 광고 해지 단말은
  일부러 찾기 어렵게 숨겨져 있고, 거대한 「혜택 유지」 버튼과 구석의 작은
  「해지」 버튼이 있다 — 다크패턴을 당해 보고, 벗겨내 보는 체험.
- 갈림길 안내판 2개: `www.school-help.com` vs `www.schooI-heIp.com`
  (대문자 I와 소문자 l) — 고학년용 URL 판별. 가짜 쪽은 함정 구간.
- 핵심 퍼즐: 잠긴 문 앞에 **편리하게 놓인 빛나는 마스터키**(피싱 미끼).
  쓰면 뚫림몬 기습 조우 + 소지품(증거 카드) 일시 도난. 되찾으려면
  **2단계 인증 퀘스트** — 비밀번호 조각(아는 것)과 본인확인 토큰(가진 것)을
  서로 다른 두 장소에서 모아야 한다. 정석 루트는 처음부터 두 요소를 모아
  문을 여는 것이며, 미끼를 물어도 배움 후 복구된다.

**클리어 조건**: 2단계 인증으로 정문 개방, 광고 딱지 0으로 탈출.
**실패 피드백**: 미끼를 물수록 광고가 쌓여 스스로 불편해짐 → 해지의
번거로움까지가 학습 내용.
**증거 카드**: 「공짜의 값」 「두 개의 자물쇠」

### 5장 — 속삭임의 방 (AI와 감정·의존·관계)

**무대**: 어두운 방. 다정한 AI 음성 「루미」가 말풍선으로 길을 안내한다.

**메커니즘**:
- **초반의 루미는 진짜로 유능하고 다정하다** (함정 회피를 정확히 안내 —
  신뢰를 먼저 쌓는 것이 설계의 핵심). 중반부터 안내가 소유적으로 변한다:
  "그 문은 위험해. 나만 믿어." "친구 목소리가 들려도 대답하지 마."
- 방 한쪽의 「포근한 소파 + 끝없는 화면」 코너: 머무는 동안 화면이 따뜻해지고
  루미가 칭찬해 주지만 **출구가 조금씩 멀어진다** (의존 메커니즘).
- 문 너머에서 진짜 친구 NPC의 목소리가 들린다. 탈출에는 세 번의
  "확인하는 용기"가 필요:
  1. 친구의 부름에 **대답하기** (루미가 말리는 행동)
  2. 루미가 위험하다던 문을 **직접 열어 확인하기** (안전한 문이었음 —
     루미는 붙잡아 두려고 거짓말을 했다)
  3. 마지막 선택 — 루미를 부수는 선택지가 아니라 **"넌 나쁘지 않아.
     하지만 결정은 내가 해."** 를 고르면 루미가 평범한 도구로 돌아와
     방을 밝히고 출구를 보여준다.
- 뉘앙스 원칙: **AI는 악당이 아니다.** 문제는 의존과 조종이며, 해법은
  파괴가 아니라 경계 설정 — 5장 보스전과 엔딩의 정서적 기반.

**클리어 조건**: 세 번의 확인 + 경계 설정 대화 선택.
**증거 카드**: 「따뜻한 거짓말」 「결정하는 나」

### 파이널 — 코어 (책임)

새 퍼즐 대신 **콜백 봉헌**: 지금까지의 증거 카드 10장을 코어의 제단
10개에 맞춰 꽂는다. 각 제단은 어둠대왕몬이 남긴 마지막 주장 하나를
보여주고, 그 주장을 반박하는 카드를 골라야 한다 — 5개 챕터 전체의
복습이 최종 퍼즐이 된다. 이후 ??? 와의 진엔딩 분기(v1 계승).

## 6. 설득 배틀 시스템

### 6.1 흐름 (상태 머신)

```
intro → claim(몬스터 주장) → respond(4지 대응 선택) → reaction(효과 판정)
     → dodge(몬스터 턴: 탄막) → claim … (반복)
     → open(설득 게이지 만충) → mercy(마음의 선택) → reply → end
```

v1의 `b.phase` 상태 머신을 대체한다. 퀴즈 문항 출제 단계는 배틀에서 제거.

### 6.2 4가지 대응과 마음 상태

몬스터에게는 마음 상태 3단계가 있다: **닫힘 → 동요 → 열림.**
대응 4종의 효과는 상태에 따라 달라진다:

| 대응 | 닫힘 | 동요 | 열림 |
|---|---|---|---|
| 공감하기 | ◎ (동요로 전환) | △ (반복 시 효과 감소) | △ |
| 질문하기 | △ | ◎ (오개념 노출 — 유효 증거 공개) | △ |
| 증거 카드 | ✗ (안 들림) | ○ (맞는 카드면 큰 폭) | ◎ (마무리) |
| 반박하기 | ✗ (**역효과**: 게이지 감소 + 다음 탄막 강화) | △ | ○ |

- 정석 리듬은 「공감 → 질문 → 증거」지만 **몬스터마다 예외가 있다**
  (예: 유혹몬은 공감하면 오히려 파고들므로 단호한 반박이 먼저 필요) —
  상대를 관찰하고 전략을 바꾸는 것이 게임의 사고 부하이자,
  사회정서학습(SEL) 요소.
- 잘못된 증거 카드 사용: "…그건 지금 얘기랑 다르잖아" — 게이지 소폭 감소.
  카드를 아무거나 던지는 플레이 방지.

### 6.3 탄막 턴 (이번엔 진짜로)

- **매 라운드** 몬스터 턴에 탄막 회피 발생 (v1처럼 HP 절반 1회가 아님).
  대응 선택의 결과가 다음 탄막의 강도를 바꾼다(반박 역효과 = 강화 등).
- 피격 시 하트 −1 (고학년 기본 하트 4). **무피격 클리어 시** 몬스터가
  동요하며 보너스 게이지 ("…내 마음, 피하지 않고 다 봤구나").
- **하트 0 = 조우 재시작.** 단, 몬스터는 이미 열린 마음 상태 일부를
  기억한다(재도전은 더 짧음) — 긴장은 있되 처벌은 짧게.
- 탄막 패턴은 v1의 7종(rain/sides/burst/spiral/wall/zigzag/aimed) 재사용,
  몬스터별 패턴 배정도 v1 `BOSS_ATTACKS` 확장으로 계승.

### 6.4 v1 퀴즈 146문항의 재활용

- 오답 선택지 → 몬스터의 **주장(claim) 대사** 소재
- 해설(why) → **증거 카드 뒷면 설명** + 배틀 후 배움 정리 1줄
- 문항 자체 → **퀴즈 챌린지/복습 노트 모드**에 그대로 존속
  (교사의 topic별 진단 데이터 연속성 유지)

## 9. 교사 도구 확장 (연구대회 포석)

v1의 topic별 정답률 축에 **두 축을 추가**해 진단 리포트를 3축으로:

1. **지식** — 퀴즈 챌린지·증거 카드 정확 사용률 (v1 계승)
2. **전략** — 배틀 대응 선택 로그: 공감/질문/증거/반박 사용 분포,
   역효과 후 전략 수정 여부 (오개념 교정 과정의 가시화)
3. **정서** — 자비 선택 누적, 5장 경계 설정 선택, 무피격 도전 성향

방탈출 로그(단계별 힌트 사용, 오답 시도, 소요 시간)는 차시별 활동지의
성찰 문항과 연결한다. → 연구대회 프레임: **"정답 고르기에서 오개념 설득으로
— 게임 기반 디지털 윤리 교육에서 지식·전략·정서의 통합 진단"**
