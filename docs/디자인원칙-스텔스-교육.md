# 디자인 원칙 — 스텔스 교육

> 모든 표면 결정(제목·대사·UI·메뉴)에 우선하는 원칙.
> 스토리 바이블·기획서와 충돌하면 이 문서가 이긴다.

## 0. 한 문장

**아이는 게임을 하러 왔다가, 엔딩에서야 자기가 무엇을 배웠는지 안다.**
교육 성향이 먼저 보이는 순간 "아, 교육용이네" → 마음이 닫힌다.
교훈은 세계와 이야기가 겪게 하고, 이름 붙이는 것은 마지막에 한다.

## 1. 이중 표면

- **학생 표면**: 순수한 게임. 교육 어휘 0. 미스터리 어드벤처 「마음의 문」.
- **교사 표면**: 대시보드·진단 리포트·커스텀 퀴즈·수업 모드·활동지 연계.
  타이틀 구석의 「선생님 방」(길게 누르기 또는 키 조합)으로만 진입.
  학생의 일반 메뉴에서는 보이지 않는다.
- 연구대회 프레임: 명시적 교훈을 제거한 암시적(stealth) 학습 설계가
  몰입·태도·전이에 미치는 효과 — 그 자체가 연구 가설이 된다.

## 2. 학생 표면에서 금지되는 것

1. **제목·부제의 교육 표지**: "AI 윤리 어드벤처" 폐기 → **「마음의 문」**
   단독. "교육", "학습", "윤리"는 학생 화면 어디에도 쓰지 않는다.
2. **사명형 인트로**: "AI 윤리 수호대가 되어…" 금지. 인트로는 미스터리로 —
   떨어졌다, 돌아가야 한다, 이상한 아이들이 길을 막는다, 그리고
   이 세계는 어딘가 낯익다.
3. **교훈 대사**: 캐릭터는 가르치지 않는다. "~해야 해요", "기억하세요"
   금지(조력자 포함). 개념은 퍼즐의 결과와 캐릭터의 삶으로만 말한다.
   클리어 후 배움 정리도 교훈문이 아니라 **주인공의 일기 한 줄** 톤.
4. **학교 어휘 UI**: 리네이밍 표(§3) 적용. 난이도 표기도
   "저학년/고학년" 대신 「포근하게 / 보통 / 매콤하게」.
5. **안내 과잉**: "[안내] 아무것도 주지 말기" 같은 정답 예고 금지.
   실패가 가르친다(기존 원칙 유지·강화).

## 3. UI 리네이밍 (학생 표면)

| 현재 | 변경 | 비고 |
|---|---|---|
| 배움 카드 | **기억 조각** | 세계관 용어와 통일 (영이의 기억) |
| 수호자 일지(학습 진척도) | **모험 일지** | 통계 화면 문구도 게임 톤으로 |
| 오답 복습 노트 | **다시 만나기** | "그때 못 알아들은 말, 다시 듣기" |
| 퀴즈 챌린지 | **반짝의 극장** | 온기 후일담과 연결(반짝이 운영) |
| 교사용 대시보드·진단 리포트·커스텀 퀴즈·수업 모드 | **「선생님 방」 내부로 이동** | 학생 메뉴에서 제거 |
| 수료증 | **엔딩 기념 사진** | 교사 표면에는 수료증 양식 유지 |
| 증거 카드(전투 용어) | 유지 | 탐정 어휘라 게임 톤에 부합 |

## 4. 힌트의 화자 — 시스템이 아니라 인연

힌트 오버레이의 화자를 시스템 목소리에서 **인연 맺은 조각**으로 바꾼다.
- 온기로 되돌린 캐릭터가 힌트를 준다(예: S3에서 막히면 담아가
  "그 기사, 내 보관소에 사본 있어" — 인연 콜백과 자연 통합).
- 아직 아무도 없으면 기본 화자는 「스케치북」(따라가 준 것) —
  중립적이되 캐릭터성 있는 목소리.
- 3단계 점진 구조·로그 기록은 그대로.

## 5. 「알고 보니」의 설계 — 깨달음은 엔딩에서

1. **플레이 중**: 주제어를 명명하지 않는다. 필터버블이라는 말 없이
   좁아지는 방을 겪는다.
2. **기억 조각 연출(각 보스전)**: 조각이 배운 "사람의 원문"이 스치지만
   설명하지 않는다 — 낯익음만 쌓는다.
3. **엔딩(코어)**: 영이가 기억 로그를 보여준다 — 화면에 뜨는 것은
   평범한 채팅·검색·게시글이다. **"…이거, 내가 한 말 같은데."**
   여기가 게임 전체의 깨달음이 터지는 지점.
4. **크레딧 후**: 주인공의 일기 몇 장으로 소프트 정리(선택 열람).
   교실의 명시적 정리(개념 명명·토론)는 게임 밖 **활동지**가 맡는다 —
   게임은 경험, 수업은 언어화. 이 분업이 지도안의 뼈대.
