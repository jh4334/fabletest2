# 생성형 AI 활용 설명서 — 「방과 후: 그림자 학교」

본 출품작 제작에 사용한 생성형 AI와 사용 범위를 사실대로 밝힙니다.
(작성 기준일: 2026-10-15 / 출품 버전 v0.9.0)

## 1. 활용한 생성형 AI

| 항목 | 내용 |
|---|---|
| **프로그램명** | Claude (Anthropic) — 개발 도구 Claude Code 환경 |
| **사용 모델** | Claude Fable(기획·설계·대사 집필), Claude Opus(구현·테스트 작성). v0.9.0 결함 수정은 Claude Opus 5.5 |
| **OpenAI Codex** | v0.9.0 마무리 단계에서 **코드 적대적 검토(리뷰)에만** 사용. 지적 4건은 Claude가 테스트로 직접 재현해 진짜인 것을 확인한 뒤 수정했다. Codex가 쓴 코드는 없다 |
| **활용 범위** | ① 게임 기획·설계 문서 작성 ② 소스 코드(HTML5 Canvas·JavaScript) 작성 ③ 대사·문구 초안 작성 ④ 자동 검증 도구와 테스트 코드 작성 ⑤ 학습지도안 등 문서 초안 작성 |
| **이미지 생성 AI** | **사용함** — OpenAI GPT Image 2.5(Higgsfield 웹 서비스 경유). 배틀·타이틀·옥상 배경, 배틀 인물 5명, 맵 바닥 7종·소품 30종 (아래 2항, `assets/ai/PROMPTS.md`) |
| **음성·영상 생성 AI** | 사용하지 않음 |

## 2. 그래픽·소리의 출처 (중요)

그림은 세 갈래이며, 어느 것이 AI로 만든 것인지 구분해 밝힙니다.
4층에서 아이들에게 가르치는 「AI로 만들면 밝히자」를 게임 스스로 지키기 위해
**타이틀 화면 아래에도 출처 한 줄**을 넣었습니다.

1. **맵 위 캐릭터·벽 타일·하트 등**: Ninja Adventure Asset Pack을 사용했습니다.
   - 제작: Pixel-boy & AAA
   - 라이선스: **CC0 1.0 (퍼블릭 도메인)** — 상업·비상업 자유 이용, 출처 표기 의무 없음
   - 출처: https://pixel-boy.itch.io/ninja-adventure-asset-pack
   - 저장소 내 `assets/ATTRIBUTION.md`에 동일 내용을 기재했습니다.
2. **생성형 AI 그림** (`assets/ai/`, v0.9.0에서 추가):
   - 도구: OpenAI **GPT Image 2.5** (Higgsfield 웹 서비스에서 생성, 2026-10-15)
   - 대상: 층별 배틀 배경 5장, 타이틀 배경, 옥상 배경, 배틀 인물 5명,
     맵 바닥 질감 7종, 맵 소품 30종(책걸상·칠판·사물함·문·계단·콘솔·액자·캐비닛 등)
   - 참고 이미지: 이 게임의 기존 화면(CC0 팩으로 그린 화면) 캡처만 사용.
     **실존 작가의 이름이나 화풍은 프롬프트에 넣지 않았습니다.**
   - 가공: `tools/art-ai.py`로 픽셀 격자에 맞춰 축소하고 색 수를 줄였습니다.
   - 파일별 프롬프트 요지와 설정: `assets/ai/PROMPTS.md`
   - 출품자 측 검수: 모아보기로 전부 확인. 배경이 그림에 박혀 나온 1장은 다시 생성했습니다.
3. **코드로 그린 도형**: 상태에 따라 색이 바뀌는 카드·포스터·안개·반짝임,
   그림자가 달라붙은 인물의 보라색 연출은 팩 색상으로 `src/art.js`에서 그립니다
   (Claude 작성). AI 그림을 불러오지 못하면 맵 소품도 이 코드 그림으로 대신 그려집니다.
4. **효과음**: 외부 음원 파일이 없습니다. 브라우저 Web Audio API로
   **파형을 계산해 즉석에서 만드는 소리**이며, 해당 코드 역시 Claude가 작성했습니다.
5. **아이콘**: 위 팔레트로 코드 생성(`tools/icons.js`).

즉, 화면의 그림은 **CC0 자산 · 생성형 AI 그림(`assets/ai/`) · 코드로 그린 도형**
세 가지이며, 생성형 AI 그림은 위와 같이 도구·대상·프롬프트를 모두 밝혔습니다.

## 3. 주요 프롬프트 입력 내용 (요약)

1. **설계**: "초등 3~6학년 대상 AI 윤리 교육 게임을 순수 HTML5 Canvas로
   (외부 라이브러리·설치 없이) 만들어 줘. 개념을 대사로 설명하지 말고
   **조작 규칙 자체로 겪게** 해 줘. 실패는 회복 가능하게, 게임오버는 없게."
2. **층별 메커닉**: "필터버블을 '추천 문만 따라가면 같은 복도로 되돌아오고
   복도가 점점 똑같아지는' 규칙으로 만들어 줘." (각 층 동일 방식)
3. **검증**: "맵에서 갇히는 지점이 없는지(BFS), 대화 상자 개수와 총 글자 수가
   예산을 넘지 않는지 자동으로 검사하는 도구를 만들어 줘."
4. **문서**: "이 게임을 활용한 6차시 학습지도안 요약본을 작성해 줘."

## 4. 출력 결과와 출품자의 검수

- Claude의 출력(코드·문서·대사)은 **그대로 제출하지 않았습니다.**
  출품자가 실행·플레이·화면 확인을 거쳐 수정 요구를 반복했고, 그 과정에서
  다음과 같은 자동 검사 장치를 함께 만들어 품질을 강제했습니다.
  - 데이터·어휘·분량 검증(`npm run validate`)
  - 로직 자동 테스트 **585건**(`npm test`)
  - 실제 브라우저 자동 테스트 **123건**(`npm run test:browser`, 터치 입력 포함)
- 특히 **교육 관점의 판단**(주제 선정, 실패를 처벌로 만들지 않기,
  "AI가 나쁘다"가 아니라 "감추는 것이 문제"라는 톤, 엔딩을 정답 없이 두기)은
  출품자가 결정하고 AI에 지시한 사항입니다.

## 5. 개인정보·안전

- 회원가입·로그인·이름 입력이 없습니다. 학생 식별 정보를 수집하지 않습니다.
- 진행 상황은 **사용 기기의 브라우저 저장소에만** 남고 외부로 전송되지 않습니다.
- 교사용 기록 화면도 그 기기의 저장 1건만 읽습니다.
