# 스펙 — P3: 3층 「방송실 · 가짜뉴스」

> 기준서 §2의 3층. v0.3.0(1~2층) 위에 증축. 헌법(§3) 위반 반려.
> 이 스펙 밖의 것을 만들지 말 것 (4층 이상·옥상·교사 도구·BGM 금지).

## 0. 목표

2층 클리어 → 계단이 3층으로 이어짐 → 3층(소문 처리 퍼즐 + 배틀 1) 클리어
→ "옥상은 공사 중" → 클리어 화면. 40분 1차시 분량. 버전 0.4.0.

## 1. 층 구조

- 맵 3개: `studio`(방송실 허브, 15×11, fl:3) + `hall3`(3층 복도, 20×11) +
  `archive`(자료실, 15×11). lab의 계단 → hall3 입구. hall3 계단 → 클리어("옥상은 공사 중").
- **이전 층 교훈 반영**: 3층 계단은 배틀 지점에서 3타일 이내(2층의 "되돌아 걷기"
  동선 리스크 회피).
- 3층 무드 컬러: 방송빨강 `rgba(216,74,60,0.10~0.16)` (기준서 §5).

## 2. 3층 메커닉 — 「소문 오염」 (개념=메커닉)

**개념**: 퍼뜨리는 건 한 번, 되돌리는 건 두 배 힘들다.

- 방송실에 **소문 쪽지 3장**이 놓여 있다(조사로 읽음, 솔깃한 한 줄짜리).
  각 쪽지는 방송 콘솔에서 두 가지로 처리한다:
  - **[바로 방송]**: 즉시 처리 완료. 그러나 그 소문의 **오염이 복도에 번진다** —
    hall3의 지정 통로 칸들이 '소문 안개' 타일로 막히고(솔리드), 오염 게이지 +1.
  - **[확인 후 방송]**: 자료실(archive)에서 그 소문의 **사실 카드**를 먼저 찾아와야
    활성화. 오염 없이 처리 완료.
- **정정 방송(회복 경로 — 항상 안내 표시)**: 오염된 소문은 자료실에서 사실 카드를
  찾아온 뒤 콘솔에서 [정정 방송] → 안개 걷힘, 게이지 -1. 즉 잘못 방송하면
  **같은 카드를 찾는 수고 + 콘솔 왕복이 한 번 더** — "두 배 힘듦"을 몸으로.
- 오염 게이지(0~3, 숫자 병기): MAX여도 배틀 진입로는 막지 않는다(회복 원칙).
  단 오염된 통로는 지름길·카드 접근을 불편하게 만든다(소프트락 금지 —
  validate로 모든 칸 도달 가능 검증).
- 첫 [바로 방송] 전에 1회 경고(1층 단말·2층 추천 문과 같은 문법).
- 소문 3장 모두 '처리'(참 방송 또는 정정 완료) → 선배가 방송실에 나타남 → 배틀.

## 3. 사실 카드 (3층 증거 3장, floor:3)

| id | label | 대응 소문 | 의미 |
|---|---|---|---|
| fullPhoto | 원본 사진 | "급식실에 벌레 나왔대" | 잘린 사진의 전체(모형 소품이었음) |
| oldDate | 날짜 기록 | "체육관 오늘 무너진대" | 3년 전 공사 안내였음 |
| ownWords | 당사자 메모 | "전학생이 훔쳤대" | 직접 물어본 대답 |

- 자료실에서 **소문별 표지 근처**에 배치(어느 카드가 어느 소문인지 조사로 힌트).
- 배틀 정답 증거 = `ownWords`(당사자에게 직접 확인) — 선배 속마음과 맞물림.

## 4. 배틀 — 방송반 선배(그림자)

- `D.BATTLES.senior`: name `선배`, shadow 3, hearts 3, evidence `ownWords`.
- 속마음(listen): `「1등으로 알리고 싶었어.」` `「맞는지는… 안 봤어.」`
- 정답 제시: `「…물어보면 됐구나. 삼십 초면 됐는데.」`
- 말걸기 3단·절반 기억·chase 없이 기존 탄막 3종 재사용 + 신규 1종 `burst`
  (예고 후 한 지점에서 방사형 6발 — 속보처럼 터진다. 저학년 속도, 예고 1.2초).
- 약속 카드③ 「퍼뜨리기 전에 확인한다」 → 3층 계단 개방.

## 5. 예산·게이트

- 3층 신규 텍스트 **1,600자 이내**(SLICE_BUDGET 3600→5400, 층당 1,800 주석 유지).
  2층 진입~형 배틀 검사와 같은 문법으로 3층 상자 5개 이내 검사 추가.
- validate: fl:3 허용, 3층 카드 3장, senior 프로필 무결성, **오염 최악 상태
  (3건 모두 오염)에서도 전 칸 도달 가능**(BFS — 소프트락 구조 차단), 소문-카드
  매핑 정합.
- 스모크 +30건 이상: 계단 연결, 바로 방송→안개 솔리드화+게이지, 경고 1회,
  확인 후 방송(오염 없음), 정정 방송(안개 해제·게이지 감소), 3장 처리→선배 등장,
  배틀 정답/오답/절반 기억, 클리어 층 표기, **1~2층 회귀 179건 전수 존속**.
- browsertest: 3층 오염 전/후 픽셀 비교 + 선배 배틀 스크린샷.
- `npm run bump` 필수. 버전 0.4.0(engine·package 동기).

## 6. 구현 힌트

- 안개 타일: 맵 grid를 바꾸지 말고 `S.fog[mapName] = [{x,y},…]` 오버레이로
  solidAt/렌더에서 합성(세이브에 포함, load 방어). 렌더는 보라-회색 반투명
  절차 도트(팩 팔레트).
- 콘솔 UI: 기존 선택지 문법(클리어 화면 메뉴/타이틀 확인창) 재사용 —
  새 UI 발명 금지.
- 소문 상태 머신: `S.rumors = { r1: 'unread'|'read'|'aired'|'polluted'|'fixed'|'verified' }`
  수준의 단순 사전. 스모크가 전 전이를 검증.
