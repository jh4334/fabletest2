# 기획 검토 — 포켓몬 잔재 전수 조사와 v3 「언더테일 단일 노선」 확정안

> 배경: v2 기획서가 이미 "포켓몬 구조 폐기, 언더테일 단일 노선"을 선언했고
> 스토리 바이블이 "-몬 작명 전면 폐기"까지 확정했지만, 실제 빌드는 여전히
> "포켓몬 + 언더테일이 겹쳐 보인다"는 피드백을 받았다.
> 이 문서는 그 원인을 코드 수준에서 전수 조사하고, **포켓몬 요소를 완전히
> 덜어내고 언더테일 베이스의 다크한 톤으로 재정렬**하는 v3 확정안이다.

---

## 0. 결론 요약

- 기획 방향(v2 기획서·스토리 바이블)은 이미 언더테일 노선이 맞다. 문제는
  **이행이 절반에서 멈춘 것**이다.
- 가장 큰 원인: **"v1 콘텐츠 무손상 원칙" 때문에 v1 포켓몬식 게임이 통째로
  살아 있고, 새 게임에서도 그대로 걸어 들어갈 수 있다.** 한 마을에서 북쪽
  문은 포켓몬(퀴즈 배틀·증표·도감), 동쪽 문은 언더테일(설득 배틀·조각)로
  이어진다 — 두 게임이 한 세계에 공존하니 섞여 보이는 게 당연하다.
- v3 결정: **v1 월드 완전 삭제(세이브 호환 포기), 도감·증표·"몬스터" 어휘
  전면 제거, 표면 이름 교체가 아니라 원문 교체, 프레젠테이션 전반의
  다크 톤 재정렬.**

## 1. 왜 아직 섞여 보이는가 — 잔재 전수 조사

### 1-A. v1 포켓몬 게임이 통째로 살아 있다 (최우선)

- 마을(village) 워프 목록에 두 세계가 나란히 붙어 있다:
  - v1 방향: `forest`(북), `cave`(서), `lake`(동), `tower`(**needBadges: 3**
    — 증표 게이트), `meadow`(**needBoss: 혼돈몬**)
  - v2 방향: `freestreet`(S1), `tiltstreet`(S2), `traceroom` 등
- 즉 **새 게임을 시작한 아이가 북쪽으로 걸어가면 v1 포켓몬식 콘텐츠**(3지선다
  퀴즈 배틀, -몬 몬스터 35종, 증표 수집, STAGE N/5, 도감 채우기)**를 그대로
  플레이하게 된다.**
- data.js에 -몬 이름이 약 130회 잔존(홀림몬 13·편향몬 12·수집몬 12·유혹몬 11…),
  v1 목표 안내문("수집몬 되돌리기", "설원의 보스 홀림몬 되돌리기"),
  -몬을 지칭하는 lockText 다수.
- game.js에 v1 전용 처리 다수: `도감` 26곳, `몬스터` 26곳, `증표` 9곳,
  v1 맵 전용 "STAGE N/5" HUD 뱃지, v1 퀴즈 배틀 상태 머신.

### 1-B. 이름만 바꾸고 원문은 안 바꿨다

- `displayName` 계층으로 HUD·화자명만 새 이름(따라·담아…)이고, 주석에
  스스로 적혀 있듯 **"대사 원문은 점진 교체 중"** — NPC 대사 안에는 여전히
  "편향몬이 똑바로 섰다니!", "보스 홀림몬을 조심하세요" 같은 문장이 나온다.
- 세이브 키도 `ai-ethics-adventure-v1`.

### 1-C. UI·문서가 포켓몬 어휘를 유지

- 게임 상단 버튼 라벨이 여전히 **[도감]**, README·교사용 안내서도 "도감" 표기.
- 칭호·어워드에 "도감 마스터", "도감 수집가" — **수집·완성률 프레임**
  (포켓몬의 핵심 동기 구조) 잔존.
- 기획서-v2 본문 자체가 처음부터 끝까지 -몬 이름으로 서술(스토리 바이블이
  대체했지만 문서는 갱신 안 됨). README는 "몬스터 도감 → 친구 수첩"처럼
  v1→v2 대응을 설명하느라 오히려 포켓몬 어휘를 노출.

### 1-D. 구조 차원의 포켓몬 잔재

| 잔재 | 어디에 | 포켓몬적 성격 |
|---|---|---|
| 증표(뱃지) 게이트 | tower `needBadges: 3` 등 | 체육관 배지 진행 구조 |
| 도감(수집 완성) | 도감 UI·칭호·어워드 | 포획·컬렉션 완성 동기 |
| "몬스터" 종(種) 프레임 | MONSTERS 전반, 문서 | 야생 개체·종 도감 세계관 |
| 오픈 필드 + 스테이지 10 | v1 맵 21개 | 루트 뱃지 진행 |
| 3지선다 퀴즈 배틀 | v1 조우 | 턴제 메뉴 전투의 껍데기 |

## 2. 이미 언더테일 정합인 자산 — 지킬 것

이 게임의 심장은 이미 언더테일 계열이고, 이미 어둡다. 건드리지 않는다.

- **설득 배틀**: 탄막 회피 + 공감/질문/증거/반박, 마음 상태 3단계, 무피격 보너스
- **자비 시스템**과 「마음의 선택」, 안아줌/무찌름
- **카르마 「마음의 온도」**: 이사 오는 조각·빈자리·인연 콜백, 4엔딩
- **침묵 루트**(무관심 루트)와 고요 — 언더테일 제노사이드의 주제적 번역
- **서사 코어**: 버려진 학습 AI 영이, 로그아웃당한 존재들, 박사(만든 자)의
  책임 — 이미 충분히 다크한 소재
- 연출 자산: BGM 악기 소거, 읽기 전에 지워지는 대사, 빈 의자 여덟 개

## 3. v3 원칙

1. **한 세계, 한 문법.** 게임 안에 전투 문법은 설득 배틀 하나만 존재한다.
   퀴즈는 도전 극장(별도 모드)에만 산다.
2. **종이 아니라 인물.** "몬스터/도감/포획/수집" 어휘를 코드 표시 문자열과
   문서에서 전부 제거한다. 이들은 조각이고, 아이고, 주민이다.
3. **표면 교체 금지.** displayName 덮어쓰기 같은 우회를 걷어내고 원문
   데이터 자체를 새 이름으로 바꾼다.
4. **다크 톤은 프레젠테이션 전층에.** 서사만 어둡고 화면·음악·마을이 명랑하면
   톤이 갈라진다(현재 상태). 팔레트·BGM·대사 톤을 서사의 온도에 맞춘다.
5. **다크 ≠ 잔혹.** 대상은 여전히 초등 고학년. 목표 톤은 언더테일의
   폐허(Ruins)식 **적막·고독·멜랑콜리 + 마른 유머**이지, 공포·유혈이 아니다.
   스텔스 교육 층·교사 도구는 그대로 유지한다.

## 4. Phase 1 — 포켓몬 절제 수술 (기능 삭제·교체)

- [x] **S1. v1 월드 삭제.** ✅ v1 전용 맵(forest·cave·lake·tower·meadow·desert·
      library·snowfield·그림자성 등 레거시 21종)과 마을에서 그리로 가는 워프,
      v1 퀴즈 배틀 상태 머신, v1 몬스터 조우 데이터를 제거한다.
      마을 북·서·동 출구는 막거나 v2 연출(안개·정적)로 봉인.
- [x] **S2. 증표·뱃지 시스템 삭제.** ✅ `needBadges`, 증표 UI, 관련 칭호 제거.
      진행 게이트는 v2 방식(챕터 클리어 플래그)만 남긴다.
- [x] **S3. 세이브 v3 전환.** ✅ (챕터 플래그만 승계 — migrateSlotV3) `SAVE_KEY` 갱신. v1/v2 세이브는 "챕터 진행도만
      승계"하는 단순 마이그레이션 1회(따라~루미 클리어 플래그 변환) 또는
      호환 포기 중 택1 — **권장: 챕터 플래그만 승계, 나머지 포기.**
      "v1 콘텐츠 무손상 원칙"은 이 문서로 공식 폐기한다.
- [x] **S4. -몬 원문 전면 교체.** ✅ data.js의 -몬 표기 약 130곳을 새 이름으로
      원문 교체하고 displayName 우회 계층을 제거한다. 내부 id(bekkyeomon 등)는
      코드 식별자로만 남긴다(화면 노출 0).
- [x] **S5. 도감 → 친구 수첩 완전 개편.** ✅ 라벨([도감] 버튼, C키 안내)과
      수집·완성률 프레임(도감 마스터/수집가 칭호) 제거. 수첩은 "몇 명
      모았나"가 아니라 **"어떻게 만났고 어떻게 작별했나"** 의 관계 기록으로.
- [x] **S6. 어휘 정리.** ✅ 표시 문자열·문서에서 몬스터→조각/아이,
      되돌리기 안내문 재작성. README·기획서-v2·교사용 안내서에서 포켓몬
      어휘와 v1 대응 설명 삭제(문서는 v3 기준으로 다시 쓴다).
- [x] **S7. 검증 갱신.** ✅ (validate.js 어휘 린트 + smoketest v1 부활 방지 회귀) tools/validate.js의 v1 스키마(맵·도감·몬스터) 검증
      제거, "화면 노출 문자열에 -몬·도감·증표 금지" 린트 추가(재발 방지).

## 5. Phase 2 — 다크 톤 리디자인 (언더테일풍 재정렬)

- [x] **D1. 팔레트.** ✅ (황혼 앰비언트 — 마을·숲, 온기 수에 따라 옅어짐) 마을·필드 기본 시간대를 황혼~밤으로. 채도 낮춘 베이스에
      마음/온기 요소(하트·창불빛·조각)만 따뜻한 색 — "어두운 세계 속 온기"
      대비를 시각 문법으로.
- [x] **D2. 마을을 폐허의 문법으로.** ✅ (끊긴 길·꺼진 건물·빈 평상 조사 소품) 경계마을은 "버려진 것들이 흘러오는 곳"
      이라는 설정 그대로: 꺼진 간판, 멈춘 기계, 빈 의자. 온기를 쌓을수록
      불이 켜지는 기존 카르마 연출이 여기서 극적으로 살아난다(어두워야
      켜지는 게 보인다).
- [x] **D3. 사운드.** ✅ (마을·숲 BGM 단조 재편곡 + 정적 구간, 영이 라이트모티프) 마을·필드 BGM을 단조 중심으로 재편곡, 정적 구간
      허용(항상 음악이 깔리지 않게). 악기 소거/복원 연출을 전 챕터 공통
      문법으로 승격.
- [x] **D4. 텍스트 톤.** ✅ (박사·아이·할머니 대사 리라이트, 숲 표지판, 훈계조 제거) 명랑 해설조 잔재 제거(기존 T3.6 연장). 기본 톤은
      짧은 문장 + 마른 유머, 시적인 문장은 보스 마지막 대사에만. 인사말·
      안내문도 세계의 적막을 깨지 않는 온도로.
- [x] **D5. 오프닝.** ✅ (인트로 침묵 — 대화가 끝나야 음악이 흘러든다) 컴퓨터실 → 낙하 → 첫 화면을 언더테일식 침묵 연출로
      (설명 대신 정적, 목표 HUD는 유지 — 길찾기 강점은 보존).
- [x] **D6. 조연 온기 대사 2단계** ✅ (검수 완료 — 개그·페이소스 동시 성립 확인)(스토리 바이블 §3)를 다크 톤 기준으로 검수.
