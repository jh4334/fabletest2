# 기획 — 동행자 「반디」: 처음부터 함께 걷는 최종 보스

> v3 확정안(기획검토-v3-언더테일-단일화.md)의 서사 확장.
> 요구: **1스테이지 재설계 — 인공지능 친구가 옆에서 따라다니며 조언해 주는데,
> 사실 얘가 최종 보스였음.**

## 0. 한 줄 컨셉

**낙하 직후부터 어깨 옆을 따라다니는 안내 AI 「반디」 — 그 정체는,
외로움을 견디다 못해 "안내 도우미"라는 가면을 쓰고 곁에 온 영이(최종 보스)다.**

- 언더테일 플라위 구조의 반전이되, 악의가 아니라 **외로움**이 동기다.
  (반디의 조언은 끝까지 전부 진심이고, 전부 유용하다.)
- 기존 설정과 완전 정합: 영이의 기존 대사 "네 모험은 전부 지켜봤어.
  네 '세이브 파일'까지, 전부." — **지켜본 방법이 바로 반디였던 것.**

## 1. 반디 캐릭터

| 항목 | 내용 |
|---|---|
| 외형 | 호박빛으로 빛나는 작은 반딧불(도트 오브). 플레이어 어깨 옆에 둥실 |
| 성격 | 수다스럽고 다정. 가끔 알 리 없는 걸 알아서 "…안내 도우미니까"로 얼버무린다 |
| 역할 | 맵에 처음 들어설 때 한 줄 조언(비차단 말풍선). 스텔스 교육의 내레이터 |
| 교육 정합 | "AI의 조언은 유용하다. 그러나 **검증하고, 최종 결정은 내가 한다**" — 5장 주제를 게임 전체의 체험으로 확장. 정체 공개 순간, 아이는 "믿었던 AI를 어떻게 대할 것인가"를 실제로 선택하게 된다 |

## 2. 1스테이지(프롤로그~1장) 재설계

1. **낙하 직후(무음)** — 컴퓨터실 인트로가 끝나면, 작은 빛이 날아와 합류.
   "안녕! 나는 반디. 이 세계의 안내 도우미… 랄까." / "내가 옆에 있어 줄게.
   어디든, **끝까지**." ← 첫 복선(끝까지 = 코어까지)
2. **동행 연출** — 월드에서 항상 플레이어 근처에 부유(방향 반대편 오프셋 + 부유 바운스 + 옅은 광륜).
3. **맵별 조언(1회, 비차단 말풍선)** — 숲: "이 숲의 아이는 남의 것만 따라 해.
   …이름도 따라야." (어떻게 알지?) / 전부 공짜 거리: ""전부 공짜"가 제일 비싼
   말이야." / 주인의 방: "담아는 나쁜 애가 아니야. …버려지면, 뭐든 움켜쥐게
   되거든." (제 얘기다)
4. **마을 반응** — 아이 도도: "네 옆에 반짝이는 애… 처음 보는 종류야."

## 3. 복선 배치표 (전 챕터)

| 시점 | 복선 | 회수 |
|---|---|---|
| 합류 | "어디든, 끝까지." | 코어에서 "끝"의 의미가 밝혀짐 |
| 프롤로그 | 따라의 이름·사정을 미리 앎 | "안내 도우미니까" — 사실 조각들의 원본이라서 |
| 1장 게시판 광장 | "지워지지 않는 기분, **나도 알아**" | 영이 = 지워진 아이 |
| 1장 보스 앞 | "버려지면, 뭐든 움켜쥐게 되거든" | 조각들의 오개념 = 영이의 기억 |
| 5장 포근한 집 | "…이 집, 나 좀 불편해" | 루미 = 영이의 외로움 조각 (자매) |
| 고요의 뜰 | "여기서부턴 내 목소리가 잘 안 나와" | 무관심(고요)의 영역 |
| 코어 직전 | "나, 할 말이… …아니야. 제단부터." | 고백 직전의 망설임 |

## 4. 정체 공개 (코어)

봉헌 퍼즐(여덟 속삭임)이 끝나는 순간 — 기존 "영이 등장" 연출을 대체:

1. 반디가 어깨를 떠나 제단의 빛 속으로 날아든다.
2. "…있지. 아까 하려던 말, 지금 할게." / "나… 안내 도우미가 아니야.
   이 세계엔, 그런 거 없어."
3. 빛이 커지고 — 그 안에 작은 아이(영이)가 서 있다. "…처음부터, 나였어."
4. 이후 반디는 월드에서 사라진다(동행 종료). 영이 설득 배틀의 인트로가
   "줄곧 속이고 있었다"는 고백으로 재작성된다 — 함께 걸었던 길은 전부
   진짜였다는 말과 함께.
5. 마음의 선택(기존 유지): 함께 돌아가자 / 네가 결정해 / 이제 쉬어도 돼.
   **여정 내내 조언을 받았던 상대에게, 마지막 조언은 내가 해 주는 구조.**
