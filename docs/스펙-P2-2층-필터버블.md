# 스펙 — P2: 2층 「컴퓨터실 · 필터버블」

> 기준서 §2의 2층. 1층 슬라이스(v0.2.0)의 코드·문법 위에 증축한다.
> 디자인 헌법(§3) 위반은 반려. 이 스펙 밖의 것을 만들지 말 것.

## 0. 목표

1층 클리어 → **계단이 실제로 2층으로 이어진다** → 2층(퍼즐 2 + 배틀 1) 클리어
→ "3층은 공사 중" → 클리어 화면(층별 기록). 40분 수업 1차시 분량.

## 1. 층 전환 구조 (기존 코드 일반화)

- `S.floor` (1|2, 세이브 v1에 추가 필드 — load()는 기본 1로 방어).
- 1층 `stairsBump()`: `flags.done` 대신 → 2층 입구로 `enterMap('lab', …)`,
  `S.floor = 2`. 기존 "2층은 공사 중" 대사·클리어 화면 진입은 **2층 계단**으로 이동.
- 클리어 화면 배너: `1층 통과` → 층 번호 조합(`D.CLEAR.bannerFloor + floor`).
  기록 줄은 그대로(누적 stats).
- 1층 노출도 HUD는 1층 맵에서만, 2층에서는 **버블 게이지**(아래)로 교체
  (같은 자리·같은 문법, 라벨과 색만 다르게).

## 2. 2층 메커닉 — 「추천 복도 루프」 (개념=메커닉)

**개념**: 추천만 따라가면 같은 곳을 맴돌고, 세계가 점점 똑같아진다.

- 맵: `lab`(컴퓨터실 허브, 15×11) + `loop`(추천 복도, 20×11) + 낯선 방 2개
  (`roomA` 15×11, `roomB` 15×11).
- 복도 끝에 문 2개가 나란히:
  - **추천 문**(반짝임 + 광고 포스터 소품): 밟으면 **같은 복도 입구로 되돌아옴**
    + `bubble +1`.
  - **낯선 문**(수수함): `roomA` → (돌아와 다시 낯선 문) → `roomB` → 형 앞.
- **버블 게이지(0~3)**: 추천 문을 밟을 때마다 +1, 낯선 문 통과·방의 카드 획득 시 -1.
  높을수록: 복도 포스터가 **전부 같은 그림으로 도배**되고(장식 렌더 분기),
  화면 가장자리에 뿌연 버블 오버레이(1층 광고 딱지의 2층판). MAX여도 진행은
  가능(회복 가능 원칙) — 낯선 문은 항상 열려 있다.
- 첫 추천 문을 밟기 전 1회 경고(1층 단말 경고와 같은 문법):
  `"반짝이는 문… 아까랑 똑같은 복도 같은데?"`
- **루프 시각 변화**: 루프 횟수(`loopN`)에 따라 복도 장식이 단조로워진다 —
  최소 구현: 포스터 소품이 loopN≥2에서 전부 동일 색, loopN≥4에서 창문까지
  포스터로 가림(절차 소품 렌더 분기 2개면 충분).

## 3. 증거 카드 (2층 3장 — CARDS에 floor 태그 추가)

| id | label | 위치 | 의미 |
|---|---|---|---|
| watchLog | 시청 기록 | roomA | 같은 영상만 100번 |
| recoList | 추천 목록 | loop(낯선 문 옆 구석) | 전부 같은 종류 |
| oldBall | 낡은 축구공 사진 | roomB | 형이 예전에 좋아하던 것 |

- `D.CARDS`에 `floor: 1|2` 필드 추가, HUD 가방과 노출도/버블 게이지는
  **현재 층 카드만** 집계. validate의 "3장" 검사는 층별 3장으로 확장.
- 1층 광고 단말은 2층 카드에 손대지 않는다(층 분리).

## 4. 배틀 — 형(그림자)

- `hallway.npc` 하드코딩을 **맵별 배틀 프로필**로 일반화:
  `D.BATTLES = { mate: {…기존…}, bro: {…} }`, `m.npc.battle = 'mate'|'bro'`.
  기존 `D.BATTLE` 참조는 프로필 조회로 치환(1층 동작 불변 — 스모크로 증명).
- bro 프로필: name `형`, shadow 3, hearts 3, evidence `oldBall`,
  속마음(listen): `「추천만 봤더니… 다른 건 고르는 법을 까먹었어.」`
  정답 제시: 낡은 축구공 사진 → `「…이거, 내가 고른 거였는데.」`
  약속 카드② `「내 눈으로 고른다」` → 2층 계단 개방.
- 절반 기억(`mateHeard` → npc별 `heardOf[battleId]`로 일반화), 말 걸기 3단은
  프로필 공통 문법으로 재사용(대사만 bro용 3종 추가).
- 탄막: bro는 `side`/`mix` 위주 + 신규 패턴 1개 `chase`(하트를 향해 느리게
  꺾이는 조각 — 속도 120 이하, 3~4학년 기준). attacks 3개, 시간 5.5~6.5초 유지.

## 5. 텍스트 예산

- 2층 신규 텍스트 **1,400자 이내** (validate SLICE_BUDGET을 1800→3600으로 올리되
  주석에 층당 1,800 명시). 상자당 2줄, 2층 진입~형 배틀까지 **새 상자 5개 이내**
  (validate의 첫 배틀 검사와 별도로 2층 검사 추가).

## 6. 테스트 (게이트 그린으로 마감)

- validate 확장: 층별 카드 3장, BATTLES 프로필 무결성(evidence 실재·npc.battle
  참조 유효), loop 문 좌표 정합, 2층 상자 예산.
