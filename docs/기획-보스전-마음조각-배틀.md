# 보스전 재설계 — 「마음 조각 배틀」 (행동 설득)

> 결정: 보스전에서 대화식 메뉴 게임(주장 읽기 → 4지 대응 선택)을 폐기한다.
> 설득은 읽는 것이 아니라 **몸으로 하는 것**이 된다. 이 문서가 기획서
> §6(설득 배틀)의 보스전 부분을 대체한다. M1~M2의 시스템 자산은
> 상호작용 층만 갈아끼워 재사용한다.

## 0. 한 문장

**보스의 마음속(탄막 상자)에 들어가, 쏟아지는 말들을 피하면서
속마음 조각을 줍고, 결정적 순간에 몸으로 응답한다.**
대사는 전투를 멈추지 않는다 — 탄막 위를 흐르는 한 줄 추임새뿐.

## 1. 기본 루프 (모든 보스 공통)

한 라운드 = **파도 → 응답의 문**, 게이지가 찰 때까지 반복.

### ① 파도 (탄막 + 조각 수집)
- 보스가 테마 탄막을 쏟아낸다(기존 패턴 엔진). 탄막 사이에
  **속마음 조각 ✦**이 떠다닌다 — 위험을 무릅쓰고 하트로 건드리면
  보스의 속마음 한 줄이 **전투를 멈추지 않고** 화면 위로 흐른다.
  (기존 "질문하기"의 대체 — 듣기가 곧 플레이가 된다)
- 조각을 모을수록 응답 게이지가 차오른다. 피격 시 하트 감소(기존 규칙).

### ② 응답의 문 (감속 선택)
- 조각을 충분히 모으면 시간이 느려지고, 상자 가장자리에 **문 3개**가
  열린다. 각 문에는 짧은 말이 걸려 있다 — 예: 「돌려줄게」(증거 카드) /
  「아니야」(반박) / 「그랬구나」(공감). 4초 안에 **하트를 몰아 옳은 문을
  통과**한다.
- 옳은 문 = 게이지 큰 폭 + 보스 반응 한 줄. 틀린 문 = 다음 파도가
  거세진다(기존 반박 역효과 계승). 문을 못 고르고 시간이 끝나면
  파도가 그냥 이어진다(무응답도 선택).
- 어떤 문이 옳은지는 **주운 조각(속마음)이 알려 준다** — 조각을 안 줍고
  문부터 고르면 찍기가 된다. "먼저 듣고, 그다음에 말하기"의 게임화.

### ③ 페이즈 = 마음 상태 (기존 3단계 계승)
- **닫힘**: 문이 잠겨 있다. 조각만 주울 수 있다 — 들어 주기 전에는
  무슨 말도 안 통한다.
- **동요**: 문이 열리기 시작. 파도와 응답이 교차.
- **열림**: 보스 고유의 마지막 기믹(§2) + 마지막 문 하나.
- 게이지 만충 → **마음의 선택**(자비)은 유지 — 그건 대화가 아니라
  단 한 번의 결단이므로.

### 계승 규칙
- 하트 소진 → 물러남 + 상대가 게이지 절반을 기억(기존).
- 무피격 파도 보너스(기존).
- 텍스트 예산: 추임새·속마음 한 줄 40자 이하, 전투 중 차단형 대화 금지.
  페이즈 전환에만 1줄 허용.

## 2. 보스 고유 기믹 — 윤리적 행동이 곧 조작

각 보스전의 열림 페이즈(그리고 파도의 변형)는 스토리 바이블의 캐릭터와
개념을 **물리 기믹**으로 옮긴다.

| 보스 | 기믹 | 개념의 체화 |
|---|---|---|
| **따라** (프롤로그) | 튜토리얼: 조각 줍기·문 통과만 | 기본 루프 학습 |
| **담아** (S1) | 탄막 사이로 남의 정보 꾸러미가 떠다닌다 — **주워서 상자 가장자리 「돌려주기」 구멍까지 운반**(들고 있는 동안 이동 느려짐). 돌려줄 때마다 게이지↑ + 담아의 짐이 하나씩 사라진다 | 모은 것을 돌려주는 행위 자체가 공격을 대체 |
| **기울** (S2) | **상자가 기울어진다** — 탄막이 경사로 쏠리고 하트도 미끄러진다. 반례 구슬을 가벼운 쪽으로 옮겨 수평을 되찾으면 파도가 잔잔해진다 | 균형 잡기 = 편향 교정 |
| **그럴싸** (S3) | 진짜/가짜 헤드라인이 섞여 날아온다 — **진짜는 스치고(그레이즈), 가짜는 피한다.** 가짜에 닿으면 화면에 소문 얼룩이 번져 시야를 가린다 | 분별이 회피의 규칙이 됨 |
| **반짝** (S4) | 탄막 사이에 반짝이는 보상 아이템이 유혹한다 — **건드리면 함정**(폭죽 폭발+광고 얼룩). 참고 지나칠 때마다 조명이 하나 꺼지며 반짝의 맨무대가 드러난다 | 절제 = 안 건드리는 것이 플레이 |
| **루미** (S5) | **상자가 점점 포근하게 좁아진다**(중앙은 안전하고 따뜻함). 가장자리에서 들리는 친구 목소리 아이콘 쪽으로, 좁아지는 벽을 밀며 나아간다 | 편안함을 떠나는 것 자체가 조작 |
| **고요** (파이널) | 라운드마다 악기가 꺼지고 화면이 어두워진다 — 탄막이 **소리와 잔상으로만** 감지된다. 조각 대신 침묵 속의 작은 목소리를 따라간다 | 무관심의 어둠 속에서 귀 기울이기 |

## 3. 데이터·교육 접점 (교사 표면)

- **응답의 문 선택 로그** = 기존 전략 로그 계승(무엇을 골랐나, 역효과 후
  수정했나) — 단, 이제 **시간 압박 아래의 판단**이다.
- 조각 수집률(듣기 성향), 유혹 아이템 접촉 수(절제), 무응답 비율.
- **연구 프레임 강화**: 방탈출 = 숙고 판단, 보스전 = 반사 판단.
  같은 개념에 대한 두 판단 양식의 격차 자체가 진단·연구 데이터가 된다.
  ("알지만 급하면 누른다"가 데이터로 보인다.)

## 4. 기존 자산 처분

| 자산 | 처분 |
|---|---|
| 탄막 엔진(패턴 7종·무적·상자) | **핵심으로 승격** — 조각·문·기믹이 이 위에 얹힌다 |
| 게이지·마음 상태 3단계·역효과·기억·자비·물러남 | **계승** (상호작용 층만 교체) |
| 주장(claims) 데이터 | **속마음 조각 대사 + 문 구성**으로 변환 (best/unlockAt 개념 유지) |
| 증거 카드 | 문 라벨로 등장 — 방탈출 보상이 문을 "해금"하는 관계 유지 |
| 공감/질문/증거/반박 4지 메뉴, pclaim/pcards 화면 | **폐기** (프롤로그 포함) |
| 일반 텍스트 대화(전투 밖) | 유지 — 전투만 액션화 |

## 5. 구현 마일스톤 수정

- **M2.5 (신규, 다음 착수)**: 마음 조각 배틀 코어 프로토타입 —
  조각 스폰/수집, 흐르는 한 줄 텍스트, 응답의 문(감속·이동 선택),
  페이즈=마음 상태, 역효과·기억 이식. 담아 보스전을 이 방식으로 교체
  (운반 기믹 포함). 메뉴식 설득 코드는 제거.
- M3 이후 보스는 처음부터 이 방식으로 제작.
- 검증 기준: 보스전 1회 중 차단형 텍스트 노출 3회 이하(인트로·페이즈
  전환·자비), 나머지는 전부 조작 중.
