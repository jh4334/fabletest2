# 기획 M라운드 — 「언더테일 감각」 이동·보스전 리워크

> 2026-07-11. 사용자 피드백: "움직일 때마다 매끄럽지 않고,
> 보스 플레이가 언더테일이랑 많이 다르다."
> 기준서 v4의 톤·설득 문법은 유지하되, **조작감과 배틀 호흡**을
> 언더테일 문법으로 다시 잡는 라운드.

---

## 1. 진단 — 왜 "언더테일보다 약한가"

### 1-1. 이동감 (world)

| 현재 코드 | 체감 문제 |
|---|---|
| 칸(48px) 단위 그리드 이동, 한 칸 9프레임 (`MOVE_SPEED = TS/9`) | 발이 끈적하다 |
| 칸 이동 중 입력 완전 무시 (`updateWorld`의 보간 중 `return`) | 방향 전환이 최대 9프레임 늦는다 — "밀리는" 느낌의 정체 |
| 대각선 없음 (`else if` 체인) | 8방향 게임에 익숙한 아이들에게 답답함 |
| 워프 후 12프레임 쿨다운 + 이동키 해제 | 방 이동 직후 한 박자 멈춤 |

언더테일은 **자유 픽셀 이동**(그리드 없음, 8방향, 즉시 반응)이다.
"언더테일 느낌"의 절반은 배틀이 아니라 이 발밑 감각에서 나온다.

### 1-2. 보스전 (persuade battle)

| 언더테일 | 현재 마음 조각 배틀 |
|---|---|
| **턴제**: [메뉴 턴] ↔ [탄막 턴] 반복 | 실시간 연속 (파도 → 문 → 자비) |
| 메뉴에서 **ACT(행동)를 고른다** — 적마다 다른 행동 목록 | 행동 선택 없음 (회피·수집·문 고르기만) |
| **매 턴 적이 대사로 반응** — 배틀이 대화다 | 배틀 중 대화 없음 (인트로/승리 대사뿐) |
| 매 턴 시작 "\* 관찰 한 줄" 플레이버 텍스트 | 없음 |
| 올바른 ACT를 쌓으면 SPARE 가능(노란 이름) | 게이지가 차면 자비 페이즈 |
| 탄막이 적의 **성격을 말한다** (파피루스의 뼈, 언딘의 창) | 패턴은 있으나 턴이 없어 인상이 흐릿함 |

현재 구조는 "미니게임 3종 세트"에 가깝다. 설득이 **대화의 왕복**으로
느껴지려면 턴 구조가 필요하다.

## 2. 기획 — M 라운드 3종

### M-1. 이동감 리워크 (2단계)

**M-1a. 그리드 개선 (저위험, 즉시)**
1. **이동 중 입력 버퍼**: 보간 중에도 방향키를 읽어 두고, 칸 도착
   프레임에 즉시 다음 이동/방향 전환. 정체 제거.
2. **대각선 허용**: 두 방향 동시 입력 시 X·Y 모두 이동
   (한 축이 막히면 나머지 축으로 미끄러짐 — 벽 슬라이드).
3. **속도 상향**: TS/9 → TS/7 (한 칸 7프레임). 스프린트는 두지
   않는다(맵이 작음).
4. **탭=방향 전환**: 정지 상태에서 짧은 탭(3프레임 이하)은 제자리
   방향 전환만 — 조사 방향 맞추기가 편해진다.

**M-1b. 자유 픽셀 이동 (본명, M-1a 검증 후)**
- 그리드 스냅을 버리고 언더테일식 자유 이동: 8방향, 대각선 정규화
  (÷√2), 히트박스는 발밑 작은 사각형(24×16).
- 충돌은 타일 AABB — SOLID 타일과 사각형 겹침 검사.
- **기존 데이터 무수정**: 상호작용(z)·워프·퍼즐 판정은
  "픽셀 위치 → 타일 좌표 환산"(`Math.round(px/TS)`)으로 그대로 동작.
- 봇/스모크 호환: `setPos`는 픽셀도 같이 스냅하므로 테스트 훅 유지.
  `hold(key, n)` 기반 이동 검증은 프레임 수만 재보정.
- 리스크: 게시판 광장 사본 추격·창고 레버 등 "칸 위에 선다" 판정이
  느슨해짐 → 판정 반경을 타일 중심 거리 ≤ 0.6칸으로 통일.

### M-2. 보스전 — 턴제 설득 대화로 재구성

**핵심 루프 (언더테일 문법, 설득 소재):**

```
[내 턴]  ← 플레이버 텍스트 "* 따라가 빈 종이만 바라본다."
  메뉴: 말 걸기 / 증거 보여주기 / 가만히 듣기 / 마음 안아 주기
    ├ 말 걸기(ACT): 보스별 행동 3~4개. 고르면 보스가 대사로 반응
    │   (올바른 행동 → 마음 게이지 +, 틀린 행동 → 다음 탄막 거세짐)
    ├ 증거 보여주기: 모은 증거 카드 제시 — 보스 약점 카드면 크게 흔들림
    ├ 가만히 듣기: 탄막 턴에 속마음 조각(✦)이 떨어짐 — 주우면 게이지 +
    └ 마음 안아 주기(MERCY): 마음이 '열림'일 때만 성공 → 자비 선택
[상대 턴]  ← 5~7초 탄막 (기존 패턴·기믹 재사용)
(반복 — 마음 상태: 닫힘 → 흔들림 → 열림)
```

- **매 턴이 대화**: ACT/증거마다 보스 반응 대사 1상자. 배틀 대본은
  보스당 반응 8~12줄 (PERSUADE 프로필에 `acts`, `reactions` 추가).
- **탄막 턴 단축**: 기존 파도(무한 지속)를 5~7초 턴으로 컷.
  파도의 "조각 줍기"는 「가만히 듣기」 선택 시의 특수 턴으로 흡수.
- **문(gates) 페이즈**: 폐지하지 않고 보스당 1회의 "중대 질문" 턴으로
  압축 — 메뉴 대신 3지선다 문이 열린다 (기존 자산 재사용).
- **마음이 열리면**: 이름이 노랗게 (언더테일 SPARE 문법),
  안아 주기 선택 시 기존 mercy 선택지로 연결.
- **HP·게임오버 없음 유지**: 탄에 맞으면 "마음의 거리"가 멀어질 뿐
  (게이지 감소), 몇 대 맞아도 물러나기만 안 하면 계속.
- 이행 순서: **따라(프롤로그) 1종을 프로토타입** → 감각 확인 후
  담아~영이 7종 확산. 보스별 기믹(소포·기울기·진실 조각…)은
  탄막 턴의 개성으로 이식.

### M-3. 연출 주스 (병렬)

1. **인물별 목소리 blip** — 대사 타자기 효과음의 음정을 인물별로
   (따라=높음, 고요=아주 낮음, 반디=맑음, 영이=반디와 같은 음정
   — 복선). 언더테일 개성의 1등 공신.
2. **화면 흔들림·히트스톱** — 탄 피격 3프레임 정지 + 2px 흔들림,
   마음 열림 순간 6프레임 정지 + 플래시.
3. **배틀 박스 크기 전환 애니메이션** — 턴 전환 시 박스가 부드럽게
   늘어나고 줄어듦 (언더테일 특유의 연출).
4. **"\*" 내레이션 문법 통일** — 배틀 내 관찰/시스템 텍스트는
   `* `로 시작 (인물 대사와 시각적으로 구분).
