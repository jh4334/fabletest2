# 기준서 — 「방과 후: 그림자 학교」 v1 (2026-07-25)

> 전면 리부트. 이전 게임(마음의 문/미결 우체국)의 코드·에셋·문서는 폐기한다
> (git 히스토리에만 보존). 이 문서가 유일한 설계 기준이다.

## 0. 한 줄 정의

방과 후 학교에 갇힌 아이가, **AI 윤리를 어겨 그림자에 씌인 학생·선생님들을
설득으로 되돌리고**, 폭주한 교내 AI를 멈춰 **학교를 탈출**하는
방탈출 어드벤처. (초등 3~6학년 · 인공지능윤리 디지털연구대회 출품작)

## 1. 스토리 뼈대

- 주인공은 방과 후 교실에 홀로 남은 아이. 교내 AI 도우미 **「나비스」**가
  폭주해 방송으로 학교 문을 모두 잠근다.
- 나비스는 학생·선생님들이 AI를 쓰며 어긴 윤리(개인정보 유출, 표절,
  가짜뉴스 유포…)를 학습해 **그림자**를 만들었고, 어긴 사람에게 그림자가
  씌었다.
- 층마다 씌인 인물을 **설득 배틀로 그림자를 벗겨** 되돌리면 다음 층 계단이
  열린다. 옥상 안테나에서 나비스와 최종 대면 → 교문 개방 = 탈출.
- **안전 프레임(대회 심사 대비)**: 공격 대상은 사람이 아니라 사람에게 씌인
  그림자다. 되돌린 인물은 아군이 되어 힌트를 준다. 최종 흑막도 사람이 아닌
  폭주 AI 시스템이며, 엔딩에서 "나비스를 어떻게 할 것인가"(고쳐서 함께 /
  끄기)를 선택해 **만든 것에 대한 책임**을 다룬다.

## 2. 층 구조 = 5주제 = 5차시 (층당 40분 수업 1차시)

| 층 | 공간 | 주제 | **층 고유 메커닉 (개념=메커닉, 심부름 금지)** | 씌인 인물 |
|---|---|---|---|---|
| 1층 | 교실·복도 | 개인정보 | **노출도 게이지**: 내 정보 카드를 흘리면 그림자가 늘고 화면에 광고딱지가 붙는다. 회수하면 내려간다 | 짝꿍 (비번 공유) |
| 2층 | 컴퓨터실 | 필터버블 | **추천 복도 루프**: "네가 좋아할" 문만 따라가면 같은 복도 반복. 낯선 문을 골라야 전진 | 게임중독 형 (추천만 시청) |
| 3층 | 방송실 | 가짜뉴스 | **소문 오염**: 확인 없이 방송 버튼을 누르면 복도가 오염되어 길이 막힘. 정정 방송은 2배 힘듦 | 방송반 선배 (미확인 속보) |
| 4층 | 미술실 | 생성AI·저작권 | **출처 스티커**: 출처 없는 그림이 걸린 문은 안 열림. AI 사용 표시+원작자 표기를 붙여야 통과 | 미술 선생님 (AI 그림 무단 전시) |
| 5층 | 교무실 | AI 의존·책임 | **조작권 잠식**: "나비스에게 맡기기"를 누를수록 내 이동 버튼이 하나씩 회색이 됨. 스스로 하기로 되찾음 | 교감 선생님 (전부 AI 결재) |
| 옥상 | 안테나 | 종합·책임 | 5개 층에서 얻은 **약속 카드**로 나비스의 질문에 답하는 최종 설득 | 나비스 (AI) |

## 3. 디자인 헌법 (전작 실패에서 배운 것 — 위반 시 반려)

1. **개념=메커닉.** 지식은 대사가 아니라 몸으로 겪게 한다. "○개 모으기"류
   심부름 금지.
2. **텍스트 예산 총 15,000자.** 대화 상자당 최대 2줄, 연속 3상자 초과 금지,
   **게임 시작~첫 배틀까지 5상자 이내.** (전작: 52,000자·첫 배틀까지 19상자 → 사망)
3. **실패는 존재하되 회복 가능.** 게이지·오염·잠식은 나빠질 수 있어야 긴장이
   생긴다. 단 회복 경로를 항상 화면에 보여준다. 게임오버 없음.
4. **층 = 40분.** 층당 퍼즐 2개 + 배틀 1회 + 정리. 넘치면 자른다.
5. 다크하되 무섭지 않게. 유혈·공포 금지. 유머 1층당 1개 이상.
6. 화면 노출 문자열에 `몬스터·도감·-몬 작명` 금지 (validate 어휘 린트 유지).

## 4. 배틀 — 「그림자 벗기기」

- 씌인 인물과 대면 → 내 턴 [**말 걸기 · 보여주기(증거) · 가만히 듣기**] ↔
  상대 턴(짧은 탄막 회피, 하트는 0이 안 됨).
- 듣기로 속마음이 열리고 → 층에서 주운 **증거**를 보여주면 그림자 게이지가
  깎인다 → 게이지 0 = 그림자가 벗겨지고 인물이 돌아온다(이름이 노랗게 →
  「손 내밀기」로 종료).
- 되돌린 인물은 그 층에 남아 한 줄 힌트 + **약속 카드** 1장을 준다.
- 배틀 1회 총 3~4턴 이내로 짧게. 전작의 8~10턴 금지.

## 5. 아트 — CC0 팩 + 팔레트 준수 자작 소품

- 베이스: **Ninja Adventure (CC0, pixel-boy)** — `assets/pack/`에 이식,
  출처는 `assets/ATTRIBUTION.md`.
- 규격: 16px 격자, 화면 3배 스케일(타일 48px). 캔버스 720×528 (15×11 타일).
- 캐릭터 시트: 64×112 (4열×7행 16px). 주인공=ninja_blue, 선생님=samurai 계열.
  **씌임 상태 = 동일 스프라이트에 보라-검정 틴트 오버레이**(별도 에셋 불필요).
- 부족한 학교 소품(칠판·책걸상·사물함·모니터)은 **팩 팔레트 색만 사용**해
  16×16 자작 도트로 추가. 장면 전체 자작 금지(품질 리스크), 소품 단위만.
- 층별 무드 컬러: 1층 노을주황 / 2층 모니터청록 / 3층 방송빨강 / 4층 물감보라 /
  5층 서류회색 / 옥상 밤하늘남색.

## 6. 기술

- 순수 HTML5 Canvas + JS. 빌드·런타임 의존성 0. **file:// 더블클릭 실행 보장**,
  PWA 오프라인 캐시(sw.js, `npm run bump`로 해시 갱신).
- 코드: `index.html` + `src/engine.js`(루프·입력·렌더) + `src/data.js`(맵·대사·
  퍼즐·배틀 데이터) + `src/art.js`(에셋 로더) — 데이터와 엔진 분리.
- 테스트 게이트(전작 인프라 계승, 새로 작성): `npm run validate`(데이터·어휘
  린트) · `npm test`(스모크) · `npm run playtest`(봇 완주, P2에서) ·
  `npm run test:browser`(실브라우저, P2에서).
- 세이브: localStorage 슬롯 3개. 교사 도구(대시보드·차시 모드)는 P3에서 이식.

## 7. 오케스트레이션 (다중 AI 루프)

- **Fable(메인)**: 기준서·층 스펙·대사 집필, 에셋 검수, 리뷰 최종 판정.
- **Opus(서브에이전트)**: 층 단위 구현 + 테스트 작성.
- **Codex**: 구현 diff 적대 리뷰 + rescue 대안 구현. *(플러그인·CLI 설치 완료,
  OAuth는 환경 네트워크 정책에 auth.openai.com·chatgpt.com·api.openai.com
  허용 후 `codex login --device-auth`로 합류)*
- 흐름: Fable 스펙 → Opus 구현(테스트 그린) → Codex 적대 리뷰(가능 시) →
  Fable 판정·커밋. 층 단위 반복.
