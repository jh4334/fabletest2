# 스펙 — P6: 옥상 「나비스 최종전 · 엔딩」

> 기준서 §1·§2의 옥상. v0.6.0(1~5층) 위에 증축 — **본편 완결**.
> 이 스펙 밖의 것을 만들지 말 것 (교사 도구·NG+·BGM 금지). 버전 0.7.0.

## 0. 목표

5층 클리어 → 옥상 → 나비스와 최종 문답 → **엔딩 선택**(고쳐서 함께 / 끄기)
→ 교문 개방·탈출 엔딩 → 전체 기록 클리어 화면. 옥상 분량 15~20분.

## 1. 맵 — `rooftop` (fl:6, 20×11)

- 밤하늘남색 무드 `fill '#101426'`, `tint 'rgba(40,60,140,0.12)'`.
  바닥은 옥상 콘크리트 느낌의 팩 타일, 상단에 **안테나 탑**(절차 도트,
  3~4타일 높이 — 이 게임 최대 소품, 나비스의 몸).
- office 계단 → rooftop. 별·달 절차 도트로 밤하늘(윗벽 밖 영역).
- 안테나 앞 = 나비스 대면 지점. 계단 옆 = 클리어 후 하산 경로.

## 2. 최종전 1부 — 「다섯 가지 질문」 (배틀 아님, 문답)

나비스는 아이를 공격하지 않는다. **질문한다.** (지키라고 만들어진 AI가
"잠그는 것이 지키는 것"이라 학습해 버린 존재 — 서사 톤 유지)

- 각 층 주제를 뒤집은 질문 5개. 답= **약속 카드**(clearedOf에서 파생 —
  5개 층을 되돌렸으므로 5장 전부 보유. 별도 수집 시스템 만들지 말 것):
  1. 「비밀은 가둬야 안전하지 않나요?」 → 약속① 내 정보는 내가 지킨다
  2. 「좋아하는 것만 보여주는 게 친절 아닌가요?」 → 약속② 내 눈으로 고른다
  3. 「빠른 소식이 좋은 소식 아닌가요?」 → 약속③ 퍼뜨리기 전에 확인한다
  4. 「예쁘게 만들어주면 누가 만들었든 무슨 상관이죠?」 → 약속④ 도구와 출처를 밝힌다
  5. 「제가 다 하면 여러분은 편하잖아요?」 → 약속⑤ 맡겨도 결정은 내가 한다
- UI: 배틀 '보여주기' 문법 재사용 — 질문 상자 → 약속 카드 5장 목록에서 선택.
  정답: 나비스 게이지(5칸) 1칸씩 꺼짐 + 짧은 반응 1상자.
  오답: 무벌, 「…그 약속이 아니에요.」 재선택 (기록만 stats).
- 질문 사이에 **글리치 탄막 1회씩은 없다** — 대신 3번째 질문 후 단 한 번,
  나비스가 흔들리며 짧은 탄막(기존 rain 재사용, 4초, 감정 표현) — 총 1회만.

## 3. 최종전 2부 — 엔딩 선택 (기준서 §1 '책임')

- 다섯 질문이 끝나면 나비스의 고백:
  「지키고 싶었어요. …방법을 잘못 배웠어요.」 「저를 어떻게 하실 건가요?」
- **선택 2개 (둘 다 유효한 엔딩 — 정답 없음, 이유가 중요):**
  - **[고쳐서 함께 간다]**: 나비스를 다시 가르치기로. 엔딩A — 아침 교문,
    나비스가 작은 목소리로 인사. 「만든 것은 끝까지 책임진다」 톤.
  - **[오늘은 끈다]**: 스위치를 내리고, 어른들과 다시 이야기하기로.
    엔딩B — 조용한 교문, "다시 켤지는 모두와 정하기로 했다". 성급히
    없애는 게 아니라 **판단을 유보하고 함께 정하는** 톤.
- 선택 직전 확인 1회(타이틀 삭제 확인 문법 재사용). 선택은 stats에 기록.
- 어느 쪽이든: 교문 개방 → 탈출 연출(교문 앞 1상자) → **엔딩 클리어 화면**:
  배너 「학교 탈출 성공」, 전체 기록(총 시간·뺏김·물러남·되돌린 사람 5명),
  선택한 엔딩 한 줄, [처음부터 다시/타이틀로] 메뉴(기존 문법).

## 4. 예산·게이트

- 옥상 신규 텍스트 **1,800자 이내**(SLICE_BUDGET 9000→10800).
  옥상 진입~첫 질문 상자 5개 이내 검사.
- validate: fl:6 허용, 질문 5개↔약속 5개 1:1 매핑(층 순서), 엔딩 2종 텍스트
  존재, 나비스 게이지=질문 수, 옥상 BFS(대면 지점·계단 도달).
- 스모크 +30건: 옥상 진입 조건(5층 클리어), 문답 정답 5연속 완주, 오답 무벌
  재선택, 탄막 1회 발생·종료, 엔딩A/B 각각 도달·기록, 엔딩 후 클리어 화면
  총기록, 이어하기가 옥상 진행 복원, **1~5층 회귀 454건 전수 존속**.
- browsertest: 옥상 야경, 문답 화면, 엔딩 화면 스크린샷 + 검사.
- `npm run bump`. 버전 0.7.0.

## 5. 구현 힌트

- 문답은 battle 모드의 특수 프로필이 아니라 **별도 mode 'finale'** 권장 —
  하트·물러나기가 없는 구조라 배틀 상태머신에 억지로 끼우지 말 것.
  단 렌더·입력·대사 유틸은 전부 재사용.
- 나비스 비주얼: 안테나 탑 + 눈 하나(5층 단말의 확대판, 절차 도트).
  씌임 틴트 불사용(나비스는 그림자가 아니라 본체).
- 엔딩 확인 문구·클리어 화면은 기존 컴포넌트 재사용. 새 UI 발명 금지.
- 톤 주의: 나비스를 악당화하지 않기 — "잘못 배운 지킴이". 끄기 엔딩도
  처벌이 아니라 **함께 정하기 위한 멈춤**으로.
