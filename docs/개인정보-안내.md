# 개인정보 처리 안내 — 마음의 문

> 학교·가정 배포 시 참고용. 이 게임은 **초등학생을 대상으로** 하므로,
> 어떤 정보가 어디에 저장되는지 투명하게 밝힙니다.

## 한 줄 요약

**「마음의 문」은 어떤 정보도 외부로 전송하지 않습니다.**
모든 기록은 게임이 실행되는 그 기기의 브라우저 안에만 저장됩니다.
서버도, 계정도, 로그인도 없습니다.

## 수집·저장하는 정보

기기의 브라우저 저장소(localStorage)에만 보관되며, 인터넷으로 나가지
않습니다.

| 항목 | 예시 | 저장 위치 |
|---|---|---|
| 학생이 정한 이름(최대 6글자) | "도도" | 기기 브라우저 |
| 학습 진행·정답률 | 개인정보 6/6, 저작권 5/6 | 기기 브라우저 |
| 게임 진행 상태(어디까지 갔는지) | 3장 클리어 | 기기 브라우저 |
| 설정(자막 속도·음량·읽어주기 등) | 음량: 작게 | 기기 브라우저 |

- **이름**은 학생이 자유롭게 정하는 별명입니다. 실명·생년월일·연락처 등
  민감한 개인정보는 **묻지도, 저장하지도 않습니다.**
- 카메라·마이크·위치 권한을 요청하지 않습니다.
- 광고·추적기·분석 도구(Google Analytics 등)를 넣지 않았습니다.

## 정보가 외부로 나가지 않는다는 근거

- 게임 코드에 서버 통신 코드(`fetch`, `XMLHttpRequest`, `sendBeacon`)가
  **하나도 없습니다.** 자동 검사(CI)로 계속 확인합니다. → *확인 방법:
  저장소에서 `grep -rn "fetch\|XMLHttpRequest\|sendBeacon" src/`*
- 서비스워커는 게임 파일을 기기에 캐시해 **오프라인 실행**만 담당합니다.
  사용자 정보를 어디로도 보내지 않습니다.

## 교사·보호자가 데이터를 관리하는 방법

- **백업/내보내기**: 일시정지 → 데이터 백업·복원에서 파일(.json)로 저장.
  이 파일에는 위 표의 정보가 담기며, **교사·보호자가 직접 관리**합니다.
- **삭제**: 브라우저의 사이트 데이터 삭제(설정 → 개인정보 → 사이트
  데이터)로 모든 기록을 지울 수 있습니다. 홈 화면 앱을 삭제해도 됩니다.
- **반 현황 CSV**(교사용)는 교사가 직접 내보내 교사의 기기에만 저장되는
  파일입니다. 학생 정보를 외부 서비스로 업로드하지 않습니다.

## 여러 학생이 한 기기를 쓸 때

- 세이브 슬롯 3개로 학생을 구분합니다. 같은 기기·브라우저를 쓰면 서로의
  진행이 같은 저장소에 남으므로, 공용 기기라면 수업 후 **백업 → 삭제**를
  권장합니다.

## 문의

배포 기관(학교·교육청)의 개인정보 담당자 정책에 맞춰 이 문서를
안내 자료로 활용하세요. 서비스 제공 주체·연락처는 실제 배포 시
기관 정보로 채워야 합니다. — *확인 필요: 배포 주체 명의·연락처.*


## 읽어주기(TTS)에 대한 안내

읽어주기는 브라우저에 내장된 음성 합성 기능(speechSynthesis)을 사용합니다.
게임은 기기 내장(로컬) 한국어 음성을 우선 선택하지만, 일부 브라우저·기기
조합에서는 브라우저 제조사의 **네트워크 음성**만 제공될 수 있습니다. 이 경우
읽어 주는 문장(학생이 입력한 별명이 포함될 수 있음)이 해당 브라우저 제조사
서버로 전송될 수 있습니다. 이를 원치 않는 환경에서는 읽어주기를 끄거나,
기기 설정에서 오프라인 음성을 설치해 주세요.

## 학급 CSV로 내보내지는 항목

교사가 「학급 모드」에서 내보내는 CSV에는 슬롯 이름(별명), 진행 단계,
주제별 정답률, 자비(안아 주기) 횟수, 엔딩 종류, 플레이 날짜(연속 출석),
행동 패턴 학습 신호(원본 대조 오판정 횟수 등)가 포함됩니다. 모두 이
기기의 브라우저 저장소에서만 읽으며, 네트워크로 전송되지 않습니다.
