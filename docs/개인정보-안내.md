# 개인정보 처리 안내 — 「방과 후: 그림자 학교」

- 이 게임은 **회원가입·로그인·이름 입력이 없습니다.**
- 학생의 이름, 학번, 연락처 등 **개인을 식별할 수 있는 정보를 수집하지 않습니다.**
- 진행 상황(현재 층·게이지·기록)은 **사용한 기기의 브라우저 저장소
  (localStorage)에만** 저장되며, 외부 서버로 전송되지 않습니다.
- 교사용 화면의 「이 기기 기록」도 **그 기기에 저장된 1건**만 읽어 보여 줍니다.
- 기록을 지우려면: 타이틀 → [처음부터] 또는 교사 화면 → [기록 지우기].
  이때 지워지는 것은 **진행 저장 1건**입니다. 아래 두 가지는 남으며,
  브라우저 데이터(사이트 데이터) 삭제로 함께 지워집니다.
  - 소리 설정(켬/끔 한 글자)
  - 오류 기록 최근 5건(게임 버전·시각·오류 문구만, 개인정보 없음 — 문의 대응용)
- 광고·분석·추적 스크립트가 없습니다. 게임은 **게임을 연 주소의 파일**(코드·그림)만
  불러오며, 다른 서버로 보내는 요청이 없습니다. 첫 접속 때 그 파일을 기기에
  캐시해 두고, 이후에는 오프라인에서도 동작합니다.
  (게임 파일을 내려주는 호스팅의 일반 접속 기록은 해당 호스팅 정책을 따릅니다.)
