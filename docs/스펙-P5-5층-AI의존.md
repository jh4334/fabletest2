# 스펙 — P5: 5층 「교무실 · AI 의존과 책임」

> 기준서 §2의 5층(마지막 일반층). v0.5.0(1~4층) 위에 증축. 헌법(§3) 위반 반려.
> 이 스펙 밖의 것을 만들지 말 것 (옥상 최종전·교사 도구·BGM 금지).

## 0. 목표

4층 클리어 → 계단이 5층으로 → 5층(맡기기/스스로 하기 + 배틀 1) 클리어 →
"옥상 문에 불이 들어왔다. …다음에 올라가 보자." → 클리어 화면. 버전 0.6.0.

## 1. 층 구조

- 맵 3개: `hall5`(5층 복도, 20×11, fl:5) + `office`(교무실 허브, 15×11) +
  `docroom`(결재실, 15×11). gallery 계단 → hall5. office 안쪽 계단 → 클리어.
  계단은 배틀 지점 인접(기존 교훈 유지).
- 5층 무드: 서류회색 `rgba(147,167,174,0.10~0.14)`.

## 2. 5층 메커닉 — 「조작권 잠식」 (개념=메커닉)

**개념**: AI에 맡길수록 내 감각이 무뎌진다. 편했는데, 내가 뭘 했는지 모른다.

- 잠긴 장치 3개(교무실 캐비닛·결재실 서류함·복도 안쪽 문). 각 장치 옆에
  **나비스 단말**이 있고 조사하면 선택(콘솔 문법):
  - **[나비스에게 맡기기]**: 즉시 열림. 그러나 **의존 게이지 +1** —
    +1: 이동 속도 15%↓ / +2: 30%↓ + 조사 가능 오브젝트의 반짝임 표시 꺼짐 /
    +3: 45%↓ + 화면 가장자리 회색 안개. **회복 안내 띠는 절대 흐려지지 않는다**(헌법 §3-3).
  - **[스스로 하기]**: 그 장치의 작은 과제를 직접 푼다(아래 §3) — 느리지만
    게이지 변화 없음. 이미 맡긴 장치도 단말 재방문 → [내가 다시 해볼래]로
    과제를 풀면 **게이지 -1** (회복 경로).
- 첫 [맡기기] 전 1회 경고(각층 공통 문법): `「편해요. 대신… 조금씩, 제가 할게요.」`
  — 나비스의 목소리 톤(옥상 복선).
- 게이지 MAX여도 배틀·진행은 막지 않는다. 느려진 몸으로도 갈 수 있다.

## 3. 스스로 하기 과제 3개 (전부 기존 UI 문법 재사용 — 새 UI 발명 금지)

1. **캐비닛**: 서류 3장을 날짜 순서로 고르기(콘솔 3지선다 × 3회, 힌트는
   서류의 조사 대사에).
2. **서류함**: 결재실 안 조사로 **열쇠 위치 단서**("화분 밑이 젖어 있다") →
   해당 오브젝트 조사 → 열쇠 획득 → 서류함 개방.
3. **안쪽 문**: 문에 적힌 시간표 빈칸(콘솔 3지선다 1회, 단서는 교무실 칠판).

## 4. 증거 카드 (5층 3장, floor:5)

| id | label | 위치 | 의미 |
|---|---|---|---|
| handNote | 손글씨 가정통신문 | 캐비닛 안 | 직접 쓰던 시절의 글씨 |
| oldStamp | 낡은 결재 도장 | 서류함 안 | 하나하나 찍던 도장 |
| nameBook | 이름 수첩 | 안쪽 문 뒤 | 아이들 이름을 외워 적은 수첩 |

- 배틀 정답 증거 = `nameBook` — "나비스는 몰라도, 내가 알던 것".

## 5. 배틀 — 교감 선생님(그림자)

- `D.BATTLES.vice`: name `교감 선생님`, shadow 3, hearts 3, evidence `nameBook`,
  sheet `teacher`.
- 속마음(listen): `「나비스가 다 해 주니까 편했어.」`
  `「…그런데 오늘 내가 뭘 했는지 모르겠어.」`
- 정답 제시: `「이 이름들… 하나하나 내가 외웠었지.」`
  약속 카드⑤ 「맡겨도, 결정은 내가 한다」 → 계단 개방 + 옥상 예고 대사 1상자.
- 탄막: 기존 재사용 + 신규 `stamp` 1종 — **예고형**: 도장 찍힐 칸이 1초간
  표시된 뒤 쾅(랜덤 낙하가 아니라 읽고 피하는 형 — 저학년 배려, 동시 2칸 이하).
- 말걸기 3단·절반 기억 공통 문법(vice 대사 세트).

## 6. 예산·게이트

- 5층 신규 텍스트 **1,750자 이내**(SLICE_BUDGET 7200→9000, 층당 1,800 주석).
  5층 진입~배틀 상자 5개 이내 검사.
- validate: fl:5, 5층 카드 3장, vice 프로필, 과제↔단서 매핑 정합,
  **전 장치 잠김 상태 BFS**(단말·단서·복귀 경로 도달 가능 / 배틀·계단 미도달),
  stamp 예고 시간 하한(≥0.8초)·동시 칸 상한, 의존 게이지 감속이 0이 되지 않음
  (최저 속도 > 0 검증).
- 스모크 +30건 이상: 계단 연결, 맡기기→즉시 개방+감속 단계별 수치, 경고 1회,
  스스로 하기 3과제, 재방문 회복(-1), 반짝임 표시 on/off, 배틀 정답/오답/
  절반 기억, stamp 예고→피격, 클리어 층 표기·옥상 예고,
  **1~4층 회귀 350건 전수 존속**.
- browsertest: 감속 전/후(속도 실측), 회색 안개 MAX, 교감 배틀 스크린샷.
- `npm run bump`. 버전 0.6.0.

## 7. 구현 힌트

- 감속: SPEED 상수를 건드리지 말고 `moveSpeed()` 파생 함수(의존 게이지 참조).
- 반짝임 표시: 조사 가능 칸 위 작은 빛 점(신규 절차 도트) — 게이지 +2부터 끔.
  이 표시 자체가 이번 층 신설이면, **1~4층에도 소급 적용하지 말 것**(회귀 보호,
  5층 한정 연출로 시작).
- 나비스 단말: 1층 광고 단말과 다른 실루엣(스피커+눈 하나) 절차 도트.
- 옥상 예고: 클리어 대사에 나비스 한 줄 `「…올라오시게요? 기다렸어요.」`(복선).
