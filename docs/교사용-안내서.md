# 교사용 안내서 — 「방과 후: 그림자 학교」

## 1분 요약

1. 브라우저로 게임 주소를 엽니다. 설치·로그인 없습니다.
2. 학생은 `시작`을 누르고 바로 플레이합니다(조작: 방향키·`Z`·`X`).
3. 교사는 **타이틀 화면에서 `T`** 를 눌러 교사 화면에 들어갑니다.
   (수업 중에는 열리지 않아 학생이 실수로 들어갈 일이 없습니다)

## 조작

| | 키보드 | 태블릿 |
|---|---|---|
| 이동 | 방향키 / WASD | 왼쪽 스틱 |
| 결정·조사 | `Z` / Space / Enter | [확인] 버튼 |
| 멈춤·취소 | `X` / Esc | [취소] 버튼 |
| 소리 끄기 | `M` | (교사가 기기 음량으로) |

- 한/영 상태와 무관하게 동작합니다.
- 다른 창으로 이동하면 **자동으로 일시정지**되고, 돌아와 `Z`로 이어집니다.
- 태블릿은 **가로로** 들어 주세요(세로면 안내가 뜹니다).

## 수업 운영

- **한 층 = 한 차시(40분)**, 총 6차시. 자세한 대응은 `차시-대응표.md`.
- 시간이 모자라면 도중에 끝내도 됩니다 — 자동 저장되고, 다음 시간에
  타이틀의 [이어하기]로 그 자리에서 이어집니다.
- 교사 화면 「수업 시작」에서 **원하는 층부터 바로** 열 수 있습니다
  (앞 층 진행은 자동 처리).
- 공용 태블릿이면 수업 끝에 타이틀 → [처음부터] 로 다음 반을 위해 비웁니다.

## 자주 나오는 상황

| 상황 | 안내 |
|---|---|
| "안 깨져요 / 못 이기겠어요" | 배틀은 이기는 게 아니라 **되돌리는** 것입니다. **「가만히 듣기」를 먼저** 하도록 안내하세요. 듣기 전에는 증거가 통하지 않습니다. |
| 하트가 다 닳음 | 게임오버가 없습니다. 잠시 물러났다가 다시 가면 되고, **들었던 이야기는 기억**되어 더 짧게 끝납니다. |
| 게이지가 가득 참(노출도·버블·오염·의존) | 진행이 막히지 않습니다. 화면 아래 띠에 **회복 방법이 항상** 표시됩니다. |
| 소리가 시끄러움 | `M` 키로 끕니다(기기에 설정이 남습니다). |
| 화면이 검게 나옴 | 새로고침(F5) 한 번. 그래도면 다른 브라우저(크롬 권장). |
| 인터넷이 끊김 | 한 번 접속했던 기기는 **오프라인에서도 실행**됩니다. |

## 교사 화면(타이틀 `T`) 세 가지

1. **수업 시작** — 층을 골라 바로 시작(기존 진행은 확인 후 대체).
2. **우리 반 기록** — 그 기기의 진행·시간·뺏긴 횟수·물러난 횟수·약속 오답과
   **지도 힌트 한 줄**. 개인 식별 정보는 수집하지 않습니다.
3. **차시 안내** — 층별 주제·메커닉·핵심 발문.
