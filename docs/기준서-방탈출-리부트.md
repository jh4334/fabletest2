# 방탈출형 리부트 — 프로젝트 기준서 (v4)

> **적용일:** 2026-07-09
> **상태:** 공식 기준. 이 문서보다 늦은 결정이 있으면 이 문서를 우선한다.
> **이전 기준:** `기획서-v2-마음의-문.md`는 역사 문서로, 참고만 하고 설계 기준으로 삼지 않는다.

## 1. 프로젝트 정체성

**마음의 문**은 한국 초등 고학년 대상 AI·디지털 윤리 교육 게임이다.
겉으로는 방탈출형 설득 어드벤처, 속으로는 스텔스 교육 층 + 교사 도구다.

- 순수 HTML5 Canvas(런타임 의존성 0), GitHub Pages로 배포되는 PWA.
- **장르: 방탈출형 설득 어드벤처 (Escape Room Persuasion Adventure)**
  - 포켓몬식 수집/포획/교환 요소가 아니다.
  - 문·잠금·이상현상·단서·장치 중심의 방탈출 거리를 탐험한다.
  - 각 거리는 구역 3곳의 퍼즐을 풀어 증거를 모은 뒤, 보스와의 설득 배틀(마음 조각 배틀)로 마무리한다.
- **톤: 언더테일풍 다크(적막·고독·멜랑콜리 + 마른 유머).**
  - 다크 ≠ 잔혹. 공포·유혈 금지.
  - 포켓몬 요소(몬스터·도감·증표·배지·-몬 작명) 금지 — validate의 어휘 린트가 강제한다.
  - 등장인물은 "조각/아이/인물"로 부른다.
- 전투 문법은 **설득 배틀(마음 조각 배틀) 하나뿐**.
  - 승패/전투/HP/게임오버 같은 전투 메타포 대신 마음이 열림/잠시 물러남 중심.
  - 탄막 액션은 유지하되 언어는 설득 중심으로.
- 퀴즈는 **도전 극장(본편 밖)**에만 존재. 본편 메인 루프에는 퀴즈가 없다.
- 핵심 반전: 동행자 「반디」 = 영이(최종 보스)의 가면.

## 2. 세계관

경계마을은 사람들이 쓰다 버린 것들이 흘러와 쌓이는 곳.
마을 너머의 낯선 거리들에는 마음이 굳어 버린 존재들이 살고 있다.
무찌르는 게 아니라, 대화하고 행동으로 마음을 다시 열어 주는 여행.

여정을 따라가다 보면 **여덟 조각**의 마음을 만나게 되고(프롤로그의 「따라」,
다섯 챕터의 보스들, 고요, 그리고 마지막에 만나는 아이),
조각들이 하나둘 맞춰질수록 「영이」라는 이름과 함께 이 세계의 진짜 이야기가
서서히 드러난다.

## 3. 게임 흐름 — 5개의 거리 + 파이널 (방탈출 구조)

각 거리는 그 자체로 작은 **방탈출**이다. 구역 3곳을 돌며 퍼즐을 풀고
증거를 모으면, 그 거리의 보스와 **마음 조각 배틀**(행동으로 설득하는
배틀)로 만나 마음을 되돌린다.

| 거리 | 방탈출 컨셉 |
|---|---|
| 1장 「전부 공짜 거리」 | 접수처·게시판 광장·배달 창고 — "공짜" 뒤에 숨은 개인정보 거래 |
| 2장 「기울어진 거리」 | 메아리 골목(추천 루프)·표본 창고(반례 수집)·꺼진 거리(램프 점등) |
| 3장 「대문짝 신문사」 | 제보함(출처 확인)·편집실(원본 대조)·송출탑(정정 보도) |
| 4장 「반짝 아케이드」 | 룰렛 광장(해지 다크패턴)·회원가입 골목(가짜 도메인)·백스테이지 |
| 5장 「포근한 집」 | 전화의 방·잠긴 복도·소파 코너 — 다정함과 거리 두기 |
| 파이널 「고요의 뜰 → 코어」 | 점점 조용해지는 뜰 → 고요 → 코어 봉헌 → 영이 |

## 5. 스텔스 교육 설계

학생이 보는 화면에는 "교육"이라는 말도, 성적표도 없다.
이동하고, 말을 걸고, 방을 탈출하고, 마음 조각 배틀을 치르는 **평범한
어드벤처 게임**처럼 보이도록 의도한다.

교사용 기능은 전부 **「선생님 방」**이라는 별도 공간에 모아 학생 화면과
완전히 분리한다. (타이틀 화면에서 T 키 또는 [선생님] 버튼)

## 6. 기술 기준

- 세이브 스키마를 바꾸면 구 세이브 승계(`migrateSlotV3` 패턴)를 붙인다.
- 게임 자산을 수정했으면 `npm run bump`로 sw.js 캐시 버전을 갱신한다.
- `npm run validate`가 데이터·어휘 린트·캐시 해시를 검증한다.
