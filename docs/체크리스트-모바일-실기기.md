# 모바일 체감 점검 — 코드 감사 결과 + 실기기 체크리스트

> 2026-07 코드 레벨 감사. ✅ = 코드에서 확인·수정 완료,
> 📱 = 자동화로 검증 불가 — **실제 태블릿/폰에서 확인 필요**.

## 코드 감사 결과 (✅)

| 항목 | 상태 |
|---|---|
| 방탈출 힌트 버튼 | ✅ **수정** — 퀴즈 폐지 때 조건이 `false`로 남아 터치 기기에서 힌트 버튼이 영구히 숨어 있었음. 방탈출 중 표시되도록 복구 (H키의 터치 대응) |
| 반디 조언 말풍선 | ✅ 비차단(notice)이라 터치 조작을 요구하지 않음. TTS 켜면 읽어 줌 |
| 대화 진행 | ✅ A 버튼 = Z와 동일 경로. 첫 배틀 조작 안내는 터치 기기에서 "스틱" 문구로 분기 |
| 선택창(단말기·출구·레버) | ✅ 스틱 상/하 반복 입력 + A로 선택 (stickDirection 데드존 검증 스모크 존재) |
| 마음 조각 배틀 | ✅ 스틱만으로 조작(버튼 불필요) — 안내 문구도 터치 분기 |
| 세로 화면 | ✅ "가로로 돌려 주세요" 안내 오버레이 |
| 안전 영역(노치) | ✅ 버튼 전부 `env(safe-area-inset-*)` 반영 |
| 수첩/메뉴/선생님 버튼 | ✅ 터치 전용 DOM 버튼, 상태별 표시 토글 |

## 실기기 확인 필요 (📱)

수업 투입 전 태블릿(가로) 1대 + 폰 1대로 아래를 확인하세요.

1. **방탈출 힌트 버튼** — 접수처에서 [힌트] 버튼이 A 버튼 위에 보이는가,
   3단계 힌트가 순서대로 열리는가. (이번에 고친 부분 — 최우선 확인)
2. **황혼 화면 밝기** — 교실 조명/저가 태블릿 패널에서 마을·숲이 너무
   어둡지 않은가. (어두우면 `DUSK_BASE` 수치 하향)
3. **반디 말풍선 가독성** — 작은 화면에서 조언 텍스트가 잘리는지,
   표시 시간(5초)이 읽기에 충분한지.
4. **스틱 조작감** — 배달 창고 레버·게시판 사본 추격처럼 세밀한 이동이
   필요한 구역에서 데드존이 답답하지 않은지.
5. **배틀 파도/문** — 탄막 회피와 문 통과가 스틱으로 무리 없는지
   (특히 기울전의 "기울어지는 상자" 드리프트).
6. **TTS** — 기기 언어가 한국어가 아닐 때 읽어주기가 자연스러운지.
7. **PWA 오프라인** — 홈 화면 추가 후 비행기 모드에서 실행되는지,
   업데이트 배포 후 두 번 새로고침으로 갱신되는지.
8. **성능** — 1장 거리(광고 표식 다수)와 2장 허브(확장맵)에서 프레임
   저하가 없는지. 저사양이면 메뉴 → 화면 효과 줄이기 권장.
