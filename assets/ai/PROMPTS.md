# 생성형 AI 그림 — 도구·프롬프트·가공 기록

이 폴더(`assets/ai/`)의 그림은 **생성형 AI(OpenAI Codex)로 만들었습니다.** 4층에서 아이들에게
「AI로 만들면 밝히자」를 가르치는 게임이므로, 게임 스스로 같은 약속을 지킵니다
(타이틀 화면 아래 출처 한 줄, 이 문서, `docs/공모전-생성형AI활용설명서.md`).

| 항목 | 내용 |
|---|---|
| 생성 도구 | **OpenAI Codex**(CLI v0.155.1, 에이전트 모델 gpt-6-astra)의 내장 이미지 생성 기능 |
| 생성일 | 2026-10-15 |
| 설정 | `codex exec` 한 번에 한 장. 소품·인물은 투명 배경 PNG |
| 참고 이미지 | 이 게임의 기존 화면 캡처(CC0 Ninja Adventure 팩 타일로 그린 화면)와 팩 캐릭터 시트. 장면·인물은 Codex로 먼저 만든 1층 배경·짝꿍을 화풍 기준으로 함께 넣었습니다. **실존 작가의 이름이나 화풍은 프롬프트에 넣지 않았습니다.** |
| 이력 | 같은 날 다른 도구(Higgsfield의 GPT Image 2.5)로 초안을 만들었으나, 비교 후 출품자 결정으로 **전부 Codex 생성분으로 교체**했습니다. 지금 들어 있는 그림은 모두 Codex로 만든 것입니다. |
| 가공 | `tools/art-ai.py` — 픽셀 격자에 맞춰 축소(바닥 16px·소품 24px·장면 360×264·인물은 짝꿍 60px 기준 원본 키 비율), 색 수 축소(8~64색), 알파 경계 정리 |
| 검수 | 모아보기로 전부 확인. 어른이 아이처럼 나온 미술 선생님·교감 선생님, 짝꿍과 구분이 안 된 형, 어둡게 나온 복도 바닥은 다시 생성 |

공통 프롬프트 꼬리말(요약): *16-bit retro RPG pixel art, hard pixels, no anti-aliasing,
1px dark outline, palette like the reference, no text, no people(장면).*
