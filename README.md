# 방과 후: 그림자 학교 🏫🌒

방과 후, 폭주한 교내 AI 「나비스」가 학교 문을 잠갔다.
AI 윤리를 어겨 그림자에 씌인 친구들과 선생님을 설득으로 되돌리고,
층을 올라 옥상의 나비스를 멈춰 학교를 탈출하자.

- 대상: 초등 3~6학년 · 인공지능윤리 디지털연구대회 출품작
- 순수 HTML5 Canvas · 설치 불필요 · `index.html` 더블클릭으로 실행
- 설계 기준: `docs/기준서-방과후-그림자학교-v1.md`
- 아트: Ninja Adventure (CC0) — `assets/ATTRIBUTION.md`

## 구성 (본편 완결)

| 층 | 주제 | 체험하는 규칙 |
|---|---|---|
| 1층 교실 | 개인정보 | 흘리면 노출도가 오르고 광고가 늘어난다 |
| 2층 컴퓨터실 | 필터버블 | 추천만 따르면 같은 복도로 되돌아온다 |
| 3층 방송실 | 가짜뉴스 | 퍼뜨리기는 한 번, 되돌리기는 두 배 |
| 4층 미술실 | 생성AI·저작권 | 출처를 밝혀야 문이 열린다 |
| 5층 교무실 | AI 의존·책임 | 맡길수록 내 몸이 느려진다 |
| 옥상 | 종합 | 다섯 약속으로 답하고, 엔딩을 고른다 |

- 교사용: 타이틀에서 `T` (수업 시작 · 우리 반 기록 · 차시 안내)
- 조작: 방향키 · `Z` 결정 · `X` 멈춤 · `M` 소리 / 태블릿은 가로 + 화면 버튼
- 문서: `docs/차시-대응표.md` · `docs/교사용-안내서.md` ·
  `docs/공모전-학습지도안-요약본.md` · `docs/공모전-생성형AI활용설명서.md`
- 개인정보 수집 없음 · 첫 접속 뒤 오프라인 실행 가능
