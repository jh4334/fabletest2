# 마음의 문 🚪✨

화면 속에서, 누군가 기다리고 있다.

한국 초등학생을 위한 2D 도트 어드벤처 게임입니다. 겉으로는 그냥 신비로운
모험 이야기지만, 그 속에는 AI·디지털 시민의식 교육이 스며 있습니다 —
**학생은 그냥 게임을 하고, 교사는 「선생님 방」에서 학습을 관리**하는
이중 구조(스텔스 교육 설계)예요.

## 이 이야기는

경계마을은 사람들이 쓰다 버린 것들이 흘러와 쌓이는 곳입니다. 마을 곳곳,
그리고 그 너머의 낯선 거리들에는 마음이 굳어 버린 존재들이 하나씩
살고 있어요. 무찌르는 게 아니라, 대화하고 행동으로 마음을 다시 열어
주는 여행입니다.

여정을 따라가다 보면 **여덟 조각**의 마음을 만나게 되고(프롤로그의
「따라」, 다섯 챕터의 보스들, 고요, 그리고 마지막에 만나는 아이), 그
조각들이 하나둘 맞춰질수록 **「영이」**라는 이름과 함께 이 세계의 진짜
이야기가 서서히 드러납니다. …그 뒤는 직접 만나 보세요.

> "정답을 맞히는 것만큼이나, 어떻게 작별하는지가 중요해." — 할머니

## 게임 흐름 — 5개의 거리 + 파이널

각 거리는 그 자체로 작은 **방탈출**입니다. 구역 3곳을 돌며 퍼즐을 풀고
증거를 모으면, 그 거리의 보스와 **마음 조각 배틀**(행동으로 설득하는
전투)로 만나 마음을 되돌립니다. 모험 중에는 정답을 고르는 퀴즈가 전혀
나오지 않아요 — 퀴즈를 풀고 싶다면 별도 모드인 **도전 극장**에서
즐길 수 있습니다.

| 거리 | 방탈출 컨셉 | 배우는 것 |
|---|---|---|
| 1장 「전부 공짜 거리」 | 접수처·게시판 광장·배달 창고 — "공짜" 뒤에 숨은 개인정보 거래를 몸으로 체험 | 개인정보 · 디지털 발자국 · 동의 |
| 2장 「기울어진 거리」 | 메아리 골목(추천 루프)·표본 창고(반례 수집)·꺼진 거리(램프 점등) | 경청 · 필터버블 · 스스로 고르기 |
| 3장 「대문짝 신문사」 | 제보함(출처 확인)·편집실(원본 대조)·송출탑(정정 보도 3단계) | 가짜 뉴스 분별 · 출처 확인 · 정정 보도 |
| 4장 「반짝 아케이드」 | 룰렛 광장(해지 다크패턴)·회원가입 골목(가짜 도메인)·백스테이지 | 다크패턴 · 광고 · 2단계 인증 |
| 5장 「포근한 집」 | 전화의 방·잠긴 복도·소파 코너 — 다 해주겠다는 다정함과 거리 두기 | AI와의 관계 · 경계 설정 · 확인하는 용기 |
| 파이널 「고요의 뜰 → 코어」 | 점점 조용해지는 뜰을 지나 고요와 만나고, 코어에서 여덟 조각의 증거로 봉헌 → 영이 | 여정 전체의 마무리 |

각 거리의 보스를 되돌리면 다음 거리로 가는 문이 열립니다.

## ✦ 마음 조각 배틀

버튼으로 메뉴를 고르는 전투가 아니라, **탄막을 피하며 행동으로
설득하는** 전투예요.

- 화살표(또는 스틱)로 **하트**를 움직여 탄막을 피해요.
- ✦ 조각을 주우면 속마음이 들리고, 문이 열리면 **마음에 닿는 문으로
  하트를 통과**시켜야 마음이 열립니다. 엉뚱한 문은 역효과!
- 보스마다 고유한 기믹이 있어요 — 정보 꾸러미 나르기(1장), 저울
  기울이기(2장), 진짜/가짜 헤드라인 가려내기(3장), 반짝이는 유혹
  버티기(4장), 좁아지는 상자(5장) 등.
- 하트가 다 닳아도 게임오버는 아니에요. 잠시 물러났다가 다시
  도전하면 됩니다.
- 마지막엔 그 존재를 **어떻게 대할지** 선택이 나오고, 따뜻한 선택은
  ♥(자비)로 조용히 기록됩니다.

## ♥ 마음의 온도 (자비 시스템)와 4가지 엔딩

여정 내내 쌓은 ♥(자비)에 따라 **마을 분위기 자체가 달라집니다** —
자비를 베풀수록 마을이 북적여지고, 되돌린 친구들이 마을로 이사와
말을 걸어요. 반대로 차갑게 대한 자리는 빈 평상으로 조용히 남습니다.

여정 전체의 ♥와 마지막 순간의 선택에 따라 결말이 갈립니다. 발견한
엔딩은 타이틀 화면에 계속 수집돼요.

| 엔딩 | 조건 (대략적인 힌트) |
|---|---|
| 「집으로」 | 거의 모두의 마음을 안아 주고, 마지막에 손을 내밀기 |
| 「새벽」 | 충분히 따뜻한 여정 끝에, 그 아이 스스로 결정하게 하기 |
| 「작별」 | 그 외의 따뜻한 여정 |
| 「침묵」 | 정답만 말하고, 아무의 마음에도 머물지 않기 |

5장 클리어 시점의 **수호자 인증서**는 중간 지점으로 따로 주어지며,
이야기는 파이널(고요의 뜰 → 코어)로 계속 이어집니다.

## 스텔스 교육 설계 — 학생 표면 · 선생님 방

학생이 보는 화면에는 "교육"이라는 말도, 성적표도 없습니다. 이동하고,
말을 걸고, 방을 탈출하고, 마음 조각 배틀을 치르는 **평범한 모험
게임**처럼 보이도록 의도했어요. 학습 진행·정답률 같은 지표는 게임
안에서도 "일지"·"기억 조각" 같은 이야기 어휘로만 나타납니다.

교사용 기능은 전부 **「선생님 방」**이라는 별도 공간에 모아 학생 화면과
완전히 분리했습니다. 타이틀(세이브 슬롯) 화면에서 **T 키**(터치 기기는
화면 구석의 작은 **[선생님]** 버튼)로 열 수 있고, 학생용 일시정지
메뉴에는 노출되지 않습니다.

「선생님 방」 안에는 다음이 있습니다.

- **▤ 교사용 대시보드** — 세 학생(슬롯)의 진행·정답률·복습 잔여·
  도전과제·자비(♥)·연속 출석을 한 화면에서 비교. **Z**로 CSV 내보내기.
- **🩺 학생 진단 리포트** — 학생별 약점 주제에 **추천 차시**를 자동
  연결. 반 전체 공통 약점도 볼 수 있고, 텍스트로 내보낼 수 있어요.
- **▶ 수업 모드** — 오늘 가르칠 거리(1~5장·파이널)를 골라 그 학생
  슬롯을 해당 시작 상태로 바로 맞춥니다.
- **✎ 커스텀 퀴즈** — 선생님이 만든 문제를 JSON으로 가져와 도전
  극장에 추가.
- **🎓 수료증** — 학생의 진행도·정답률·자비를 담은 인증서 생성.

## 실행 방법

별도 설치가 필요 없습니다. 셋 중 편한 방법으로 실행하세요.

**방법 1 — 그냥 열기**

`index.html` 파일을 더블클릭해서 브라우저(크롬, 엣지 등)로 엽니다.

**방법 2 — 간단한 서버로 열기**

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

**방법 3 — GitHub Pages로 배포 (교실 공유용)**

저장소 **Settings → Pages → Source**를 **"GitHub Actions"**로 한 번
설정해 두면, `main` 브랜치에 올라올 때마다 `.github/workflows/pages.yml`이
자동으로 사이트를 배포합니다. 학생들에게 URL 하나로 나눠 줄 수 있어요.

외부 라이브러리·이미지·음원 파일이 전혀 없는 순수 HTML5 Canvas + Web Audio
게임이라 저사양 PC, 태블릿에서도 가볍게 돌아갑니다.

## 모바일 / 태블릿

화면 왼쪽 아래에 **가상 스틱(이동)**, 오른쪽 아래에 **A(결정) 버튼**,
위쪽에 **[수첩]·[메뉴] 버튼**이 표시됩니다. 이동은 4개 방향 버튼 대신
**스틱을 손가락으로 끌어** 상하좌우로 움직입니다(작은 화면·태블릿에서
더 편함, 가운데 데드존으로 오조작 방지). 버튼은 크고 또렷하게 다듬어져
누르기 쉽고, 안전 영역(노치)도 자동으로 피합니다. 세로로 들면 "가로로
돌려 주세요" 안내가 뜨고, 가로 화면에 맞춰 플레이하도록 설계돼
있습니다. (교실 태블릿 환경 권장)

터치 기기에는 키보드 단축키가 없으므로, 친구 수첩은 **[수첩]** 버튼으로
바로 열고, 그 외 일지·기억 조각·도전과제·꾸미기·도전 극장·**데이터
백업**·접근성 설정 등 **나머지 모든 기능은 [메뉴] 버튼**에서 열 수
있습니다.

**설치형 앱(PWA)** — 브라우저로 접속한 뒤 "홈 화면에 추가"를 하면
앱 아이콘으로 설치되고, 한 번 실행한 뒤에는 **네트워크 없이도** 동작합니다.
(GitHub Pages·HTTPS 환경에서 자동 적용. 교실 태블릿에 미리 한 번 열어 두면
인터넷이 끊겨도 수업이 가능합니다.)

## 조작 방법

| 동작 | 키 | 터치 |
|---|---|---|
| 이동 | 화살표 키 또는 W A S D | 가상 스틱(끌어서 이동) |
| 말 걸기 / 결정 / 조사 | Z, 스페이스, 엔터 | A 버튼 |
| 마음 조각 배틀 — 하트 이동 | 화살표 | 가상 스틱 |
| 방탈출 힌트 (3단계로 점점 자세히) | H | 메뉴 → 힌트 |
| 친구 수첩 바로 열기 | C | 수첩 버튼 |
| 일시정지 메뉴 (마을/필드에서) | X, Esc | 메뉴 버튼 |
| 수호자 일지 (마을/필드·타이틀) | J | 메뉴 → 수호자 일지 |
| 도전과제 (마을/필드·타이틀) | B | 메뉴 → 도전과제 |
| 꾸미기: 칭호·테마 (마을/필드·타이틀) | K | 메뉴 → 꾸미기 |
| 기억 조각 컬렉션 (마을/필드·타이틀) | L | 메뉴 → 기억 조각 |
| 명예의 전당 (마을/필드·타이틀) | F | 메뉴 → 명예의 전당 |
| 도전 극장 (퀴즈, 모험과 별개) (마을/필드·타이틀) | Q | 메뉴 → 도전 극장 |
| 데이터 백업·복원 (마을/필드·타이틀) | U | 메뉴 → 데이터 백업·복원 |
| 다시 만나기 (오답 복습) (마을/필드에서) | V | 메뉴 → 다시 만나기 |
| 도움말 (마을/필드·타이틀) | I | 메뉴 → 도움말 |
| 취소 / 슬롯 삭제 | X, Esc | — |
| 음악 켜기/끄기 | M | 메뉴 → 소리 |
| 대화 자막 속도 (보통/빠름/느림) | T | 메뉴 → 자막 속도 |
| **선생님 방 열기 (타이틀 화면에서만)** | **T** | **[선생님] 버튼** |
| 학년별 난이도 (저학년/기본/고학년) | 메뉴에서 | 메뉴 → 난이도 |
| 읽어주기(TTS, 접근성) | 메뉴에서 | 메뉴 → 읽어주기 |
| 큰 글씨 모드 (접근성) | G | 메뉴 → 큰 글씨 |
| 색약 모드 (접근성) | 메뉴에서 | 메뉴 → 색약 모드 |

> 대시보드·진단 리포트·수업 모드·커스텀 퀴즈·수료증은 더 이상 개별
> 단축키(옛 P/E/N)로 열리지 않습니다. 타이틀에서 **T**(또는 [선생님]
> 버튼)로 여는 **「선생님 방」**에 모여 있습니다. (스텔스 교육 원칙 —
> 학생이 보는 화면·메뉴에는 이 항목들이 전혀 노출되지 않습니다.)

## 세이브 슬롯

타이틀 화면에 **세이브 슬롯 3개**가 있습니다. 빈 슬롯을 고르면 이름을
지어 새 모험을 시작하고(여러 학생이 한 기기를 나눠 쓰기 좋아요), 채워진
슬롯은 이어서 진행합니다. 진행은 자동 저장되며, **X**로 슬롯을 삭제할 수
있습니다. 진행뿐 아니라 **학습 일지·복습 노트·도전과제·통계·방탈출
진행도 슬롯(=학생)별로 따로** 보관되어, 한 기기를 나눠 써도 학생끼리
기록이 섞이지 않습니다. (예전 버전의 세이브는 처음 실행 시 챕터
진행만 자동으로 이어받습니다.)

## ♥ 친구 수첩

마음을 되돌린 아이는 **친구 수첩(C 키/수첩 버튼)**에 기록됩니다. 각자의
이야기와 내가 한 작별 선택까지 남아요. 기록은 세이브와 별개로 누적
보존되어, 되짚어 보는 재미이자 수집 재미를 함께 줍니다.

## 방탈출 힌트

방탈출 중 막히면 **H 키**(또는 메뉴 → 힌트)로 힌트 창이 열립니다. 한
번 누를 때마다 힌트가 **한 단계씩 더 자세해지며**(최대 3단계), 정답을
바로 알려주기보다 스스로 실마리를 찾도록 돕습니다. 힌트 사용은 슬롯별
학습 기록(「선생님 방」 진단 리포트)에 남아, 어떤 방에서 많이 막혔는지
교사가 파악할 수 있습니다.

## 다시 만나기 (오답 복습)

도전 극장(퀴즈)에서 틀린 문제는 **다시 만나기** 목록에 자동 기록됩니다.
마을/필드에서 **V 키**(또는 메뉴)로 열어 다시 풀 수 있고, 맞히면 목록에서
사라집니다. 세이브와 별개로 누적 보존됩니다. (방탈출에서 힌트를 쓰거나
여러 번 틀린 기록은 이 목록이 아니라 「선생님 방」의 학생 진단
리포트에서 방별로 확인할 수 있습니다.)

## 설정·일시정지 메뉴

마을/필드에서 **X(Esc)**를 누르면 일시정지 메뉴가 열립니다. 수호자
일지, 다시 만나기, 친구 수첩 바로가기와 함께, **자막 속도**·**큰 글씨
모드**·**음소거**·**접근성 설정**을 한곳에서 켜고 끌 수 있습니다.

## 수호자 일지 (학습 진척도) · 학생별 기록

**J 키**(또는 메뉴)로 여는 **수호자 일지**는, 그동안 겪은 방탈출·퀴즈의
**주제별 정답률**을 막대그래프로 보여 줍니다. 정답률이 낮은 주제가 위로
올라오고 색으로 강조되어, 무엇을 더 살펴봐야 하는지 한눈에 보입니다.
전체 정답률·발견 엔딩·자비(♥)·복습 잔여 문제 수도 함께 표시돼요.

일지·복습 노트·도전과제·통계는 **세이브 슬롯(=학생)별로 따로** 누적됩니다.
한 태블릿을 여러 학생이 슬롯으로 나눠 써도 학습 기록이 섞이지 않고,
슬롯을 삭제하면 그 학생의 학습 기록도 함께 정리됩니다. (친구 수첩·발견
엔딩은 기기 공용 컬렉션으로 그대로 둡니다.)

## 도전과제 (업적)

**B 키**(또는 메뉴)로 여는 **도전과제** 화면에서, 학습·전투·수집·챌린지
영역의 목표들을 배지로 모읍니다. (예: *첫 깨우침, 마음의 수호자, 완벽한
한 주제, 두루 박학, 여덟 조각의 친구, 모든 결말, 챌린지 만점 …*) 달성 여부는
그 학생의 학습 데이터에서 자동으로 판정되어, 다음 목표가 자연스럽게
동기 부여가 됩니다.

## 도전 극장 (오늘의 도전 · 맞춤 학습 포함)

타이틀이나 마을/필드에서 **Q 키**(또는 메뉴)로, 모험과 완전히 별개로
즐기는 **퀴즈 모드**가 열립니다. 다음 중에서 골라 10문제에 도전하고,
마지막에 점수와 격려 메시지를 받습니다. 틀린 문제는 다시 만나기에,
결과는 수호자 일지 통계에 함께 반영됩니다.

- **◷ 오늘의 도전** — 날짜를 씨앗으로 문제가 정해져, **같은 날에는 모두
  같은 문제**를 풉니다. 완료하면 그날의 출석이 기록돼 **연속 출석(스트릭)**이
  쌓여요.
- **◎ 맞춤 학습 (약점 집중)** — 그 학생이 **틀렸던 문제와 정답률이 낮은
  주제**를 우선해서 출제하는 적응형 모드입니다.
- **★ 전체 랜덤** 또는 특정 **주제** — 원하는 범위로 자유롭게 연습.

수업 도입부 워밍업, 마무리 복습, 매일 한 판의 습관 만들기에 알맞아요.

## 오늘의 도전 · 연속 출석(스트릭)

이 슬롯으로 논 날이 **하루도 안 빠지고 이어지면** 연속 출석(🔥)이 늘어납니다.
타이틀의 슬롯과 수호자 일지·교실 리포트에 현재/최고 연속 출석이 표시되어,
꾸준히 조금씩 공부하는 습관을 자연스럽게 응원합니다.

## 꾸미기 (칭호 · 테마)

**K 키**(또는 메뉴)로 여는 **꾸미기** 화면에서, 학습·수집 성취로 **칭호**와
화면 강조색 **테마**를 모아 골라 끼울 수 있습니다. (예: *따뜻한 마음,
공부벌레, 마음 기록가, 챌린지 챔피언* 칭호 / *숲빛·바다빛·노을빛·은하빛*
테마) 고른 칭호는 일지와 교실 리포트에, 테마색은 화면 곳곳의 강조색에
반영됩니다. 새 보상이 열리면 모험 중에 살짝 알림이 떠요. 칭호·테마는
학생(슬롯)별로 따로 보관됩니다.

## 📚 기억 조각 컬렉션

**L 키**(또는 메뉴 → 기억 조각)로 여는 **기억 조각**은, 각 주제마다 한
장씩 모으는 학습 카드입니다. 그 주제를 한 번이라도 맞히면 카드가
열리며, 카드에는 *개인정보 보호, 가짜 정보 분별, 저작권, 딥페이크 분별*
등 핵심 가르침이 한 줄로 정리되어 있습니다. 배운 내용을 다시 보고, 빠진
주제를 채우는 재미를 함께 줍니다. (별도 저장 없이 정답 기록에서 자동으로
계산되므로 백업·복원에도 그대로 따라옵니다.)

## 명예의 전당 (로컬 기록)

**F 키**(또는 메뉴 → 명예의 전당)로 여는 **명예의 전당**은, 한 기기를 나눠 쓰는
세 학생(슬롯)의 **최고 기록**을 부문별로 모아 순위(🥇🥈🥉)로 보여 줍니다.
*챌린지 최고점 · 최장 연속 출석 · 안아준 마음 · 기억 조각 · 도전과제 · 친구 수첩*
부문이 있으며, 친구·형제와 선의의 경쟁으로 다시 도전할 동기를 줍니다.
(인터넷 전송 없이 이 기기 안에서만 기록됩니다.)

## 데이터 백업 · 복원

**U 키**(또는 메뉴 → 데이터 백업·복원)로, **모든 슬롯·학습 기록·다시
만나기·친구 수첩·도전과제·꾸미기·설정**을 한 파일로 모아 둘 수 있습니다.

- **내보내기** — 클립보드로 복사하거나 `.json` 파일로 저장.
- **가져오기** — 저장해 둔 파일을 골라 **다른 기기·브라우저로 그대로 옮기거나
  복원**. (가져오면 지금 기기의 기록을 덮어씁니다.)

기기를 바꾸거나 브라우저 데이터가 지워져도 진행과 학습 기록을 지킬 수 있어,
교실에서 학생 데이터를 백업·이관하기에 좋습니다.

## 커스텀 퀴즈 (선생님 문제)

「선생님 방」의 **커스텀 퀴즈** 화면에서, 선생님이 직접 만든 문제를
**JSON으로 가져와**(파일/클립보드) 게임에 추가할 수 있습니다. 추가한
문제는 도전 극장의 **「커스텀 · 선생님 문제」** 주제와 맞춤·오늘의
도전에 함께 출제됩니다. 화면에서 **문제 양식(템플릿) 복사**·**모두
지우기**도 할 수 있어, 수업 주제에 맞춘 문제를 손쉽게 운영할 수 있어요.

> 빈칸을 채우는 방식으로 문제를 만들고 싶다면 `tools/editor.html`을 두 번 눌러
> 여세요(인터넷 불필요). 글자 수·정답까지 확인해 JSON으로 저장/복사한 뒤
> 위 "가져오기"로 넣으면 됩니다. 교사용 안내서·활동지는 `docs/` 폴더에 있어요.
> (`docs/교사용-안내서.md`는 아직 v1 기준 설명이 남아 있어 v2 갱신이 필요합니다.)

```json
{ "questions": [
  { "q": "문제 (줄바꿈은 \\n)", "a": ["보기1", "보기2", "보기3"], "c": 1, "why": "해설" }
] }
```

## 학년별 난이도 모드

메뉴의 **난이도**에서 **저학년 · 기본 · 고학년**을 고릅니다.

- **저학년** — 마음 조각 배틀 하트 1개 추가, 탄막이 더 느리고 부담이
  적어요.
- **기본** — 표준 속도·하트 개수.
- **고학년** — 탄막이 조금 더 빠르고 조밀해 도전적입니다.

## 읽어주기 (TTS, 접근성)

메뉴의 **읽어주기**를 켜면, 대화·문제·보기·해설·힌트와 마음 조각
배틀의 주요 순간까지 **음성으로 읽어 줍니다**(브라우저 음성합성 사용).
읽기가 서툰 저학년이나 글 읽기가 어려운 학생도 소리로 내용을 따라갈 수
있어요. (지원하지 않는 브라우저에서는 조용히 꺼집니다.)

## 접근성 (큰 글씨 · 색약 모드 · 도움말)

- **큰 글씨(G)**: 대화·목록 등 읽기 화면의 글자와 줄간격을 키웁니다.
- **색약 모드**: 정답률 막대·정답/오답 표시의 색을 빨강/초록 대신 구분이
  쉬운 파랑/주황(Okabe–Ito 계열)으로 바꿉니다. 색뿐 아니라 ○/× 기호와
  소리로도 결과를 알려, 색 구분이 어려워도 문제없이 즐길 수 있어요.
- **화면 효과 줄이기**: 오답·피격 시의 전체화면 번쩍임과 화면 흔들림,
  어두운 방의 비네트 효과를 크게 줄여, 빛 번쩍임에 민감한 학생도 안전하게
  즐길 수 있어요. 첫 실행 시 운영체제의 **"동작 줄이기
  (prefers-reduced-motion)"** 설정을 자동으로 따릅니다.
- **도움말(I)**: 조작·마음 조각 배틀·방탈출 힌트·메뉴 기능을 짧게
  안내합니다. 처음 시작한 학생에게는 **첫 마음 조각 배틀에서 한 번**
  간단한 전투 안내도 떠요.

색약 모드·화면 효과 줄이기는 게임 중 **X(메뉴)** 안에서 켜고 끌 수 있고,
자막 속도·큰 글씨와 함께 세이브와 별개로 저장됩니다.

고DPI(레티나·태블릿) 화면에서는 글자가 또렷하게 보이도록 기기 픽셀 밀도에
맞춰 렌더링합니다. 진행이 저장되지 않는 환경(비공개 모드·저장공간 가득)에서는
타이틀에 경고가 표시되며, 데이터 백업으로 기록을 따로 보관할 수 있어요.

## 설치형 앱(PWA)·오프라인

`manifest.webmanifest` + `sw.js`(서비스워커)로 **앱 설치와 오프라인 실행**을
지원합니다. HTTPS(예: GitHub Pages)로 한 번 접속하면 모든 게임 파일이
캐시되어, 이후에는 인터넷 없이도 동작합니다. 브라우저의 "홈 화면에 추가"로
전체화면 앱처럼 설치할 수 있어, 교실 태블릿 배포에 적합합니다.
아이콘은 `node tools/icons.js`로 생성합니다.

## 살펴보기

어디서나 **Z(또는 A 버튼)**으로 주변을 살펴볼 수 있습니다. 방탈출의
소품 하나하나에 실마리가 숨어 있고, 마을 곳곳에는 이야기의 복선도
숨어 있습니다.

```bash
node --check src/*.js    # 문법 검사
node tools/validate.js   # 데이터 무결성 + 스키마 검사
node tools/smoketest.js  # 게임 로직 스모크 테스트 (플레이 경로, 900여 개)
node tools/slottest.js   # 세이브 슬롯 시스템 테스트 (24개)
node tools/browsertest.js # (선택) 실제 브라우저 렌더링 테스트 (Playwright 필요)
npm run docs             # 교사용 주제별 문제 목록 문서 재생성
npm run pack             # 오프라인 배포용 ZIP 생성
```

## 퀴즈 수정·추가하기

코드를 고치지 않고 **게임 안에서** 문제를 추가하려면, 「선생님 방」의
**커스텀 퀴즈**에서 JSON 파일을 가져오면 됩니다. (위 *커스텀 퀴즈* 항목 참고)

기본 문제를 직접 수정하려면 `src/data.js`의 `QUIZZES`에 문항을 추가합니다.
(퀴즈는 도전 극장과 미래연구소 보너스 지역, 그리고 v1 레거시 경로에서
쓰이며, 5개 거리의 방탈출·마음 조각 배틀에는 쓰이지 않습니다.)

```js
{
  q: '문제 (줄바꿈은 \n)',
  a: ['보기1', '보기2', '보기3'],
  c: 1,            // 정답 번호 (0부터)
  why: '해설 (정답이든 오답이든 항상 표시됩니다)',
}
```
